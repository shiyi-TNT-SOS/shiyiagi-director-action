# 环境氛围设计层：让环境成为第五个角色

> 在本 skill 之前，环境只以两种身份出现：**功能性空间**（`fight-design.md` 第三节：道具 / 死角 / 高度差）和**力量证据的零件**（扬尘 / 碎屑）。
> 这份文件补上第三种身份——**氛围与情绪的放大器**。
>
> **为什么值得单独立一维：环境是性价比最高的氛围升级手段。** 它不需要多人精确物理交互（AI 最弱的一环），单镜就能出，且观众对环境变化的感知是**无意识**的——不占注意力，却直接决定"这场打戏打得舒不舒服"。

---

## 零、环境的三层作用（要同时设计，不是三选一）

| 层 | 作用 | 例子 |
|---|---|---|
| **功能层** | 提供道具、死角、高度差 | 桌台、竹竿、积水、栏杆 |
| **力量层** | 承接物理反馈，让力量可见 | 碎屑、扬尘、水花、墙面裂开 |
| **情绪层** | 定调、放大、反衬 | 暴雨 vs 静默、月光 vs 血色 |

> 只有功能层 = 动作设计很扎实但没有氛围（像施工图纸）
> 只有情绪层 = 空有气氛没有支撑（像MV）
> **三层叠齐，环境才成立。**

---

## 一、环境的恶化曲线 ⭐（核心洞察）

院线动作戏几乎都在用一个隐含手法：**环境随打斗升级而逐步崩坏，充当战斗的进度条。**

```
① 开打前   环境完好：桌面整齐、灯火稳定、空气静止、水面无波
      ↓
② 中段     开始被波及：杯子震倒、灯摇晃、尘土浮起、地面出现裂纹
      ↓
③ 高潮     环境崩坏：桌翻、墙裂、火起、水漫、竹木断裂
      ↓
④ 结束     静止的狼藉 = 战斗的「账单」
```

**为什么重要**：观众判断"打得多狠"，主要不是看动作，而是看**最后一帧的狼藉**。同一套动作，环境完好收场 vs 一片狼藉收场，观感差一个档。

**AI 特别适合做这个**——环境崩坏不需要多人精确交互，单镜就能生成，比"两人贴身缠斗"稳得多。**这是用 AI 的强项补 AI 的弱项。**

### 落地：分镜表加「环境」列

- 从第 1 镜到最后一镜，环境崩坏度**单调上升**
- **不要忽好忽坏**（第 3 镜墙裂了、第 5 镜又完好 = 观众以为换了个场景）
- 最后一镜必须是**静止的**狼藉——崩坏的终点是"停"，不是"继续炸"

## 二、天气与时段调性表

先定天气与时段，再定力度调性（`style-anchors.md`）。两者是乘法关系，不是加法。

| 天气 / 时段 | 氛围 | 适配的力度调性 | 写法要点 |
|---|---|---|---|
| **暴雨** | 混乱、掩盖、冷酷 | 癫狂、凌厉 | 水花要**短促**；别写持续水流（见第六节） |
| **雨夜** | 肃杀、临界 | 压迫感 | 雨声本身就是静默的对照物 |
| **浓雾** | 未知、遮蔽、逼近 | 压迫感、诡谲 | 雾只能遮**环境**，不能遮主体轮廓 |
| **逆光黄昏** | 悲壮、告别 | 悲壮 | 长影 + 剪影，主体半暗 |
| **正午硬光** | 赤裸、无遮掩 | 干净利落、狠辣 | 影子短而硬，无处可藏 |
| **夜色 + 单光源** | 聚焦、审讯感 | 压迫感 | 单光源 = 画面唯一可读区 |
| **风** | 动感、蓄势 | 帅气、凌厉 | 风要"停"得恰到好处——预备拍风停=张力 |
| **火** | 危险、失控 | 癫狂、暴烈 | **唯一会自主恶化的元素**——它会自己改变环境状态 |
| **雪** | 静、慢、留痕 | 悲壮、干净利落 | 落雪 = 天然升格素材；雪地留痕 = 免费的轨迹记录 |
| **沙 / 尘** | 苍凉、粗粝 | 悲壮、压迫感 | 尘悬浮比尘飞扬更"闷" |

> **天气不是装饰，是约束。** 暴雨意味着"看不清"（所以打斗要更清晰）、夜意味着"只能靠光"（所以光源要设计）、雾意味着"距离失效"（所以空间关系要重新交代）。

## 三、环境在四拍中的角色（环境 = 第五个角色）

| 拍 | 环境的角色 | 例子 |
|---|---|---|
| **预备** | 环境「**静**」 | 风停、雨缓、尘落、水面无波、灯火将熄未熄 |
| **冲击** | 环境「**炸**」 | 碎屑四溅、水花泼起、墙面裂、桌翻 |
| **结果** | 环境「**余波**」 | 尘缓缓落下、水洼涟漪、烟向上飘 |
| **反应** | 环境「**归位**」 | 一切静止，只余狼藉 |

**关键：①的「静」与 ②的「炸」之间的落差，就是力度的落差。**

这和 `production.md` 的"冲击前 0.2 秒静默"是**同一件事**——只是用环境做，不用声音做。两种用法：

- **叠加**：环境静 + 声音静 → 最狠，但每场最多用一次
- **只用环境**：环境静但保留环境音 → 更高级，更耐磨（观众不会预料到）

## 四、氛围词 → 环境元件转译

用户说"要那种氛围"时，按这张表落到环境上：

| 氛围词 | 环境元件 |
|---|---|
| **压抑** | 浓雾 + 低照度 + 单光源 + 无风 + 尘埃悬浮 |
| **肃杀** | 雨夜 + 无风 + 远处闷雷 + 水面静止 |
| **史诗感** | 大远景 + 低角度云 + 逆光剪影 + 风 |
| **诡谲** | 顶光或底光 + 影子方向反常 + 雾贴地不贴人 |
| **苍凉** | 黄昏逆光 + 长影 + 稀疏植被 + 风沙 |
| **窒息感** | 封闭空间 + 尘埃悬浮 + 单光源 + 无环境音 |
| **张力临界** | 一切静止 + 只有一处微动（灯火将熄未熄 / 水将滴未滴） |
| **孤独 / 对峙** | 大远景 + 主体极小 + 大量留白 + 风 |

> 这些词本身**不进 prompt**（见 `concept-translation.md`），要展开成上面的环境元件。

## 五、AI 生成环境的三个技巧

### 1. 环境反馈比人物动作稳，优先用环境

AI 做"被击者的夸张反应"容易崩（肢体精度弱），但做"墙面碎裂 / 水花溅起 / 桌面震动 / 尘土飞扬"很稳。
**所以力量证据尽量放在环境上**——这与 `fight-design.md` 第五节的「力量证据外部化」完全同源，只是这里从"动作设计"推广到"氛围设计"。

### 2. 流体要短，不要持续

持续的动态流体（雨砸积水四溅、水流奔腾）容易糊。改成**短促的、定格式的**：

- ✅ "积水被踩得向上溅起，水花悬在半空"
- ✅ "水洼荡开一圈涟漪"
- ✅ "逆光中雨丝可见，地面水面静止"
- ❌ "大雨倾盆，雨水不断砸在水面溅起水花"

### 3. 环境不能抢主体

氛围元素（雾、尘、光斑、雨丝）只能是"**边**"，不能是"**体**"：

- 浓雾不要遮主体轮廓（遮环境不遮人）
- 尘埃不要密到看不见地面
- 光斑不要盖在脸和武器上
- **判据**：把环境元素全部去掉，主体动作还应成立——成立就对了

## 六、分镜表加「环境」列（这是唯一的落地手段）

没有这一列，氛围永远是"写 prompt 时临时想一句"。有了它，环境才会被真正设计。

**改造后的分镜表**：

| 镜号 | 拍 | 时长 | 景别角度 | 运镜 | 画面内容 | **环境** | 声音 |
|---|---|---|---|---|---|---|---|
| 1 | 预备 | 2s | 大全景 | 静止 | 两人对峙 | **雨夜竹林，空气静止，水面无波，一盏将熄的灯** | 雨声 |
| 2 | 冲击 | 1s | 中景 | 甩镜 | 刀气横扫 | **三根竹竿齐口断裂，水花溅起** | 竹裂 + 破空 |
| 3 | 结果 | 1s | 特写 | 定格 | 收刀空档 | **雨水沿刀脊滑落，地面裂纹蔓延** | 刀身余震 |
| 4 | 预备 | 3s | 低角仰拍 | 缓推 | 举刀蓄力 | **周身雨水被蒸成白汽，草向四周倒伏** | 低频轰鸣 |
| 5 | 冲击 | 1s | 大全景 | 静止 | 瞬身切入 | **起点光尘残留，地面被气劲压出浅坑** | 剑鸣 |
| 6 | 结果 | 2s | 特写 | 定格 | 剑抵咽喉 | **一滴血落进积水，血丝缓缓散开** | 闷响后静默 |
| 7 | 反应 | 2s | 中景 | 缓拉 | 弃刀对峙 | **满地断竹与泥水，一切静止（狼藉）** | 雨声复现 |

**看这一列**：从"水面无波"到"满地断竹"，崩坏度单调上升，最后一镜静止——这就是免费的氛围进度条。

## 七、环境氛围负面词（可直接附加）

```
浓雾遮挡主体、背景杂乱、环境元素过多、
过重的雾、霾、灰尘过重、水面湍急、雨幕过密、
雾气遮住人物轮廓、灰尘覆盖主体
```

> 前几项是通用实物类，后几项是环境氛围专属。**`no text / 无字幕` 依然不要写。**

---

## 八、自检清单（环境氛围）

- [ ] 环境三层都设计了（功能 / 力量 / 情绪），不是只挑了一层
- [ ] 分镜表有「**环境**」列，且崩坏度**单调上升**
- [ ] 最后一镜是**静止的狼藉**（战斗的账单），不是"继续炸"
- [ ] 天气与时段已定，且与力度调性**匹配**（不是随手挑的）
- [ ] 预备拍环境「静」、冲击拍环境「炸」，落差成立
- [ ] 没有持续的动态流体（都改成了短促 / 定格式）
- [ ] 去掉所有环境元素后，主体动作仍然成立（环境是"边"不是"体"）
- [ ] 浓雾 / 尘 / 光斑没有遮住主体轮廓
- [ ] 氛围词已转译成环境元件，没有裸词进 prompt
- [ ] 负面词含环境氛围类，不含 `no text / 无字幕`
