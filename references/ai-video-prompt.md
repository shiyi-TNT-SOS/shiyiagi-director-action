# 分镜 → 视频模型提示词（动作场景转换规则）

## 七段顺序（句首权重最高，顺序不能乱）

```
[主体动作] + [景别角度] + [单个运镜] + [光线] + [色彩] + [画幅+时长] + [声音]
```

> **环境氛围写在「光线」与「色彩」之间**——它和光线同属视觉氛围家族，不单独立段（七段顺序保持不变）。环境的写法与崩坏度设计见 `environment-atmosphere.md`。

| 段 | 内容 | 示例 |
|----|------|------|
| 主体动作 | 谁、做什么、重心怎么移 | 黑衣人右拳由腰侧旋身直击对方下颌，重心左移 |
| 景别角度 | 景别+角度 | 中近景，15°低角度仰拍 |
| 单个运镜 | 只写一个核心运镜 | 甩镜加速 / 定格1–2帧 |
| 光线 | 方向+硬度+色温（**本段含环境氛围**，顺序：光线 → 环境 → 色彩） | 硬光侧逆光勾边；暴雨，积水被踩得向上溅起、水花悬在半空 |
| 色彩 | 主色+点缀 | 青灰底+暖血色点缀 |
| 画幅+时长 | 固定 2.39:1 + 秒数 | 2.39:1 电影画幅 / 1秒 |
| 声音 | 台词或音效 | 打击音效+环境回响 |

> 主体动作永远句首。把"电影感""8K""超高清"放句首 = 把预算花在没用的词上。

## 动作场景硬约束（必查）

- [ ] 时长按口径：**生成单元 4–10 秒，成片动作镜 1–2 秒**（一条 prompt 出 4–10 秒动作单元，剪辑取其中 1–2 秒成镜；余量是给剪辑留的余量，不是浪费，详见 `references/fight-design.md` 第九节）；一镜只放四拍中的一拍。
- [ ] 画幅标注 2.39:1，主体占画面 ≥60%。
- [ ] 排除文字用构图（"画面留白处无标识"），**不写"无字幕/无文字"**（会反被召唤出文字）。
- [ ] 多人接触简单或移出画面，不写复杂同框微操。
- [ ] 观感词已转译，无裸用形容词。
- [ ] 台词短、有张力；无台词只给音效与环境音，无背景配乐。

## 引擎参数差异

**完整能力矩阵、选引擎决策树、负面词的两种写法，统一见 `production.md` 第四章「引擎能力矩阵」**（含 2026-10 快照）。引擎事实只维护那一处，避免四处漂移。

动作场景额外需要记住的：

- **一镜一拍 + 2.39:1**：2.39:1 是极宽画幅，主体必须够大，否则打击点看不清；这也是竖屏适配的最大冲突点（见 `platform-specs.md` 第三章）。
- **多人物理脆弱**：任何引擎都一样。接触动作简单化或移出画面，不要指望引擎解决穿模。
- **运镜迁移（复刻参考视频的运动）**选可灵 Motion Control，是当前最可靠的一条。
- **需要精确落首尾帧**（打击点要与下一镜反应对齐）优先可灵。
- **单 prompt 多镜**（Shot 1/2/3）在 Seedance 系可用，但动作戏建议还是一镜一拍，别把四拍塞进一条 prompt。

## 反例（不要这样写）

- ❌ "电影感炸裂的帅气打斗，8K超高清无字幕" — 全是废词 + 触发文字召唤 + 句首浪费。
- ❌ 一镜写"先甩镜再慢动作再跟拍" — 运镜打架，模型糊。
- ❌ "两个人激烈缠斗" — 多人物理脆弱，必崩。

## 超现实场景的七段写法（奇幻 / 修仙 / 超能力）

七段顺序不变，但**「主体动作」段必须承载"过渡态"**，另外有三处专属约束。

| 段 | 写实版 | 超现实版 |
|---|---|---|
| 主体动作 | 谁·做什么·朝哪 | 谁·做什么·朝哪 **+ 中间态的可见纹理**（光尘/气浪/残影）+ 停在何处 |
| 景别角度 | 景别+角度 | 同上，但瞬移镜必须**写"两个位置同框"** |
| 单个运镜 | 一个核心运镜 | 瞬移镜**固定机位、无运镜**（运镜会让同框失效） |
| 光线 | 方向+硬度+色温 | 同上；能力光效要写明**颜色与位置**，别让光盖住人 |
| 色彩 | 主色+点缀 | 同上；超现实加一层"能力色" |
| 画幅+时长 | 2.39:1 + 秒 | 同上；瞬移镜 3–4s，变速的快段 1s、慢段 3–4s |
| 声音 | 音效/环境音 | 同上；超现实加"能力音"（剑鸣/气旋轰鸣/光尘簌簌） |

### 三条硬约束

1. **主体动作段里，位移必须有载体。** 不写"他瞬移过去"，写"他在原地化作蓝色光尘向上消散，人已出现在三米外"。
2. **瞬移镜不写运镜。** 机位固定是"起点终点同框"的前提；一甩镜，观众就读不到"消失+出现"同时发生。
3. **慢动作只写一个动作，且点名看什么。** "慢动作，剑尖停在咽喉前一寸，血从口角缓缓溢出"——不要"慢动作，他打出一套拳"。

### 超现实负面词（固定附加）

```
凭空出现、生硬切镜、物体突然冒出、
多余肢体、多余手指、扭曲的脸、模糊五官、塑料感皮肤、
画面闪烁、抽帧卡顿、过曝、水印、乱码、镜面反射
```

> 前三个是超现实专属。**`no text / 无字幕` 依然不要写。**

### 正例（这样写）

瞬移镜：
```
蓝衣剑客在原地化作蓝色光尘向上消散，同一画面里他已在三米外的石阶上凝出人形、剑尖前指，
起点残留最后几缕光尘；固定机位，大全景，两个位置同框；无运镜；冷蓝月光；
青灰冷调加蓝色光尘；2.39:1 电影画幅 / 4秒；一声清越的剑鸣
```

升格镜：
```
慢动作，他的剑停在距对方咽喉一寸处，剑身仍在轻微震颤，一缕被削断的发丝缓缓飘落；
固定机位，特写；定格1帧；硬光侧逆光；青灰冷调；2.39:1 / 3秒；静默，只留剑身震颤的嗡鸣
```

## 正例（这样写）

"黑衣人旋身右拳直击下颌重心左移，中近景15°低角仰拍，甩镜加速，硬光侧逆光勾边，身后木架被撞翻、木屑与灰尘扬起，青灰底暖血色点缀，2.39:1电影画幅/1秒，拳风破空音效+闷响"

> 环境氛围插在「光线」与「色彩」之间。**判据：去掉所有环境描写，主体动作仍应成立**——成立就说明环境是"边"不是"体"。
