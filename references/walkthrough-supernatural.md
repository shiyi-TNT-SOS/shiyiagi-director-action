# 端到端完整示例：一场仙侠竹林夜战，从 brief 到逐镜提示词

> 本文件是**唯一的完整走通的案例**。前面各文件教方法，这份文件示范"这些方法按什么顺序、产出什么格式、最后长什么样"。
>
> **用法**：把它当输出的格式模板。每次交付超现实打斗，都按这个顺序和表结构出，只是内容换成用户的那一场。
>
> 涉及的方法来源：设计层 `supernatural-fight-design.md`、单镜写法 `supernatural-fight.md`、四拍与提示词顺序 `action-director-prompt.md` / `ai-video-prompt.md`。

---

## 第 0 步：用户 brief（原始输入，就这么多）

> "来一段仙侠打戏，两个剑客在竹林里打，要那种瞬移的，带慢动作，主角比较弱但最后赢了。"

按 `SKILL.md` 第 1 步补齐成 6 项，**缺的标为假设**：

| 项 | 内容 | 来源 |
|---|---|---|
| 场景 | 雨夜竹林，竹竿密集，地面湿滑有积水 | 用户说"竹林"，天气与时辰为假设 |
| 人物 | 蓝衣剑客（主角，境界低）vs 黑甲刀客（境界高，用长刀） | 用户说"两个剑客"；刀客/境界差为假设（用户说"主角比较弱"，必须给个强对手） |
| 武器 | 长剑 vs 长刀 | 假设 |
| 力度 | **凌厉** | 假设（用户说"瞬移+慢动作"，偏凌厉；待用户确认） |
| 观感词 | **瞬移、慢动作（升格）** | 用户原话 |
| 画幅时长 | 2.39:1，共 7 镜 | 默认 |

---

## 第 1 步：签「能力契约」

> 方法见 `supernatural-fight-design.md` 第一节。**这一步不写，后面全是特效对轰。**

| 要素 | 内容 |
|---|---|
| **剑客的能力** | 「三步瞬身」——短距离瞬移，**必须先看见目标位置**才能移过去（可见效果：原地化作蓝色光尘，在新位置凝聚） |
| **刀客的能力** | 「断岳」——举刀聚气后的一记大范围斩击，刀气可劈开身前一切（可见效果：刀身缠绕黑色气旋，斩出时地面开裂） |
| **代价与盲区** | 剑客：瞬身三次后力竭、口角溢血。刀客：**起手大招前有半拍"收刀空档"**——旧力已尽、新力未生，护门大开 |
| **胜负条件** 制伏（不致死，合规） |
| **情报差** | 刀客不知道剑客会瞬身；剑客知道刀客的大招前摇很长 |

**每个能力都有可见形态** ✅（光尘凝聚 / 黑色气旋 / 地面开裂）——没有"很强"这种能力。

---

## 第 2 步：定克制关系

**关系：被克制者胜。** 刀客境界高、正面碾压，剑客只能靠"瞬身打他大招前的空档"翻盘。

三条纪律落位：
1. 境界差**不是纯数值**——刀客强在正面，剑客强在"能出现在刀客想不到的位置"
2. 大招「断岳」**有被反制的可能**——起手前半拍是空的
3. **反制线索必须提前埋**：第 3 镜专门给一个"刀客收刀时刀身低垂、护门空缺"的特写

---

## 第 3 步：重定义空间

竹林的地形意义全部换成**能力的作用范围与盲区**：

| 竹林的物理特征 | 在能力规则下的意义 |
|---|---|
| 竹竿密集遮挡视线 | **遮蔽感知**——剑客瞬身前必须"看见目标"，竹竿密的地方反而不能乱移 |
| 两人相距八米 | 刀客的刀气覆盖范围之内 → **对剑客是危险区** |
| 地面湿滑积水 | 可被能力波及（剑气扫起水花）+ 慢动作的细节素材 |
| 无出口（竹林纵深） | 强化"退无可退"，逼出瞬身 |

> 设计空间时问的是"**哪些位置对谁不安全/到不了**"，不是"这里有什么竹子"。

## 第 4 步：情报战四段式 → 分镜表

| 镜 | 阶段 | 拍 | 时长 | 景别角度 | 运镜 | 画面内容 | 声音 |
|---|---|---|---|---|---|---|---|
| 1 | ① 试探 | 预备 | 2s | 大全景，固定机位 | 静止 | 雨夜竹林，两人相距八米，刀客刀气在身前划出一道弧线，削断三根竹竿 | 雨声、远处闷雷 |
| 2 | ① 试探 | 冲击 | 1s | 中景，侧拍 | 甩镜加速 | 刀客旋身横斩，剑客侧身让开，刀气擦过他衣角，身后两根竹竿齐口断裂 | 刀气破空 + 竹裂 |
| 3 | ① 试探 | 结果 | 1s | 特写，固定 | 定格 1 帧 | **刀客收刀，刀身低垂、胸腹护门空缺半拍**（反制线索埋点） | 雨声，刀身余震嗡鸣 |
| 4 | ② 暴露 | 预备 | 3s | 低角度仰拍 | 缓慢推近 | 刀客被激怒，举刀过顶，刀身缠绕黑色气旋，雨水在刀周被蒸成白汽 | 低频轰鸣渐起 |
| 5 | ③ 反制 | 冲击 | 1s | 大全景，固定机位 | 静止 | **剑客原地化作蓝色光尘消散，同一画面里出现在刀客背后，光尘在身后残留半瞬**；起点终点同框 | 一声清越剑鸣 |
| 6 | ③ 反制 | 结果 | 2s | 特写，固定 | 定格 1–2 帧 | 剑尖停在刀客咽喉前一寸，刀客瞳孔收缩；剑客单膝跪地，口角溢出一缕血 | 闷响后**静默** |
| 7 | ④ 终结 | 反应 | 2s | 中景 | 缓慢拉远 | 刀客刀脱手落地，黑色气旋溃散；剑客以剑支地站起，两人在雨中对峙 | 雨声复现，无配乐 |

镜数 7（在 4–8 区间）✅。**注意第 5 镜的两个硬规则**：机位固定、起点终点同框。

## 第 5 步：一攻一应表（超现实版六要素）

| 拍 | 谁发起·用哪个能力 | 作用目标 | 命中/闪避/免疫 | 对方用什么反制 | 空间如何被折叠 | 给下一拍留的接口 |
|---|---|---|---|---|---|---|
| 1 | 刀客，刀气横斩 | 剑客腰侧 | 闪避 | 剑客侧身让开（无能力，纯身法） | 无 | 刀气削断的竹竿倒向画面右 |
| 2 | 剑客，试探瞬身 | 刀客身后 | 落空 | 刀客回身横刀，刀气扫过剑客原站位 | 瞬身位移约两米 | **刀客收刀、护门空缺** |
| 3 | 刀客，起手大招「断岳」 | 剑客（范围） | 未命中（被反制） | 剑客瞬身切入背后 | 瞬身穿透刀气范围 | 光尘残留在起点 |
| 4 | 剑客，剑抵咽喉 | 刀客咽喉 | 命中（制伏） | 刀客弃刀 | 无 | **剑客单膝跪地、口角溢血**（代价） |
| 5 | — | — | — | — | — | 剑客以剑支地站起（余势） |

**第 6 列全部是"代价或盲区被暴露"**——这是超现实版的接口，也是下一拍的素材。✅

## 第 6 步：逐镜提示词（可直接复制）

> 七段顺序：**主体动作 → 景别角度 → 单个运镜 → 光线 → 色彩 → 画幅+时长 → 声音**。
> 每镜只放一拍，无"然后/接着/再"。

**镜 1（试探 · 预备）**
```
雨夜竹林大全景，两名剑客相距八米对峙，右侧黑甲刀客身前刀气划出一道弧线、削断三根竹竿，
竹竿缓缓倒向画面右；固定机位，大全景，无运镜；冷蓝月光从竹梢缝隙斜下；
青灰冷调加水面反光；2.39:1 电影画幅 / 2秒；雨声与远处闷雷，无背景配乐
```

**镜 2（试探 · 冲击）**
```
黑甲刀客旋身横斩，刀气擦过蓝衣剑客衣角，身后两根竹竿齐口断裂、断面平整；
中景，侧面平拍；甩镜加速；冷调硬光；青灰底加刀光冷白；2.39:1 / 1秒；刀气破空声与竹裂声
```

**镜 3（试探 · 结果）★ 反制线索埋点**
```
黑甲刀客收刀，刀身低垂横在膝前，胸腹护门空缺，雨水沿刀脊滑落；
特写，固定机位；定格1帧；侧逆光勾边；冷调青灰；2.39:1 / 1秒；雨声与刀身余震的嗡鸣
```

**镜 4（暴露 · 预备）**
```
黑甲刀客举刀过顶，刀身缠绕黑色气旋，周身雨水被蒸成白色水汽向上腾起；
低角度仰拍，中景；镜头缓慢推近；低照度，逆光剪影；冷调加黑色气旋；
2.39:1 / 3秒；低频轰鸣渐起
```

**镜 5（反制 · 冲击）★ 瞬移镜**
```
蓝衣剑客在原地化作蓝色光尘向上消散，同一画面里他已在刀客背后凝出人形、剑尖前指，
起点位置残留最后几缕光尘，终点位置衣摆尚未完全落定；固定机位，大全景，两个位置同框；
无运镜；冷蓝月光；青灰冷调加蓝色光尘；2.39:1 / 1秒；一声清越的剑鸣
```

**镜 6（反制 · 结果）★ 停点 + 代价**
```
蓝衣剑客的剑尖停在黑甲刀客咽喉前一寸，刀客瞳孔收缩、喉结微动，
剑客单膝跪地、口角溢出一缕血；特写，固定机位；定格1-2帧；硬光侧逆光；
青灰冷调加一线暖色血痕；2.39:1 / 2秒；一声闷响后转入静默
```

**镜 7（终结 · 反应）**
```
黑甲刀客手中长刀脱手落地、插入泥水，黑色气旋溃散成细屑，蓝衣剑客以剑支地缓缓站起，
两人在雨中对峙；中景；镜头缓慢拉远；冷蓝月光；青灰冷调；2.39:1 / 2秒；
雨声复现，无背景配乐
```

### 负面词（每镜固定附加）

```
凭空出现、生硬切镜、物体突然冒出、
多余肢体、多余手指、扭曲的脸、模糊五官、塑料感皮肤、
画面闪烁、抽帧卡顿、过曝、水印、乱码、镜面反射
```

> 前三个是超现实专属（见 `supernatural-fight.md` 第七节），后面是通用实物类。**不要写 `no text / 无字幕`。**

## 第 7 步：生产要点（这一场要特别注意什么）

| 项 | 做法 |
|---|---|
| **一致性** | 剑客与刀客各出一张定妆图；武器（长剑/长刀）单独出正侧两张参考图，描述串逐字复用 |
| **必抽卡的镜** | **镜 5（瞬移）和镜 6（停点）**——这两镜是全片的胜负手，各出 4–6 条；其余 1–2 条 |
| **一次只改一个变量** | 镜 5 若"光尘不像"，先只改光尘的描述（密度/方向/颜色），别同时改景别和光线 |
| **瞬移翻车先查** | 光尘糊 / 出现"凭空多出一个人" / 起点终点不同框 → 见 `troubleshooting.md` 第八节 |
| **变速感** | 镜 4（3s 慢）+ 镜 5（1s 快）的时长落差，就是"超快→升格"的观感来源，**不来自任何一句 prompt** |
| **慢动作细节** | 镜 6 的慢只给"血从口角溢出、剑尖未进"这一个细节，别塞第二个动作 |
| **竖屏适配** | 镜 5 的"起点终点同框"在竖屏里改为**上下排列**（起点在上、终点在下），不要硬塞横向 |

## 第 8 步：交付前自检（对着念一遍）

- [ ] 能力契约四项齐全，每个能力都有可见形态
- [ ] 存在克制关系（被克制者胜），不是境界数值高下
- [ ] 空间约束已换成感知范围 / 遮蔽感知，没停留在"竹林里有竹子"
- [ ] 四段齐全，**③ 反制在镜 5**，且线索在镜 3 已埋
- [ ] 一攻一应表第 6 列全是"代价或盲区被暴露"
- [ ] 全场只 1 个决定性大招（镜 4「断岳」），前面有蓄力、后面有真空期
- [ ] 每镜无"然后/接着/再"，一镜一拍
- [ ] 瞬移镜机位固定、起点终点同框
- [ ] 慢动作镜只放一个简单动作，且点名了要看什么
- [ ] 负面词含 `凭空出现 / 生硬切镜`，不含 `no text / 无字幕`
- [ ] 终结落在"制伏"而非"致死"（合规）
