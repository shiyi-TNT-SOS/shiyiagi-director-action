# 风格参考坐标：把"我要那种感觉"翻译成可执行参数

> 用户说"高级感""治愈""很燃""有质感"时，这些词**不能写进提示词**（它们落不到画面上）。
> 但用户说的确实是有效的创作意图。这份文件做的事是：**意图 → 视觉特征 → 具体参数**。

---

## 一、为什么需要中间这一层

```
用户的语言          本文件的活              分镜表的语言
"要那种高级感"  →  调性 → 视觉特征 → 参数  →  85mm f/1.8 / 侧逆光 / 单色分区 / 静默
```

跳过去直接写"高级感"的后果：
- 模型把它当形容词，忽略或随机化
- 不同的镜头对"高级感"理解不一致，成片调性散掉
- 出了好片也不知道好在哪，无法复现

**中间这一层就是把模糊意图固化成可复用、可复现的参数组合。**

---

## 二、五轴映射法（把任何调性拆成 5 轴）

任何一个调性词，都能拆成下面 5 轴上的具体取值。**拆不出 5 轴 = 这个词太虚，先跟用户确认他要的到底是什么。**

| 轴 | 取值范围 | 常见错误 |
|---|---|---|
| **① 构图与景别** | 主体占画面比、留白比例、信息密度、视线朝向 | 只写"好看的构图" |
| **② 运镜与节奏** | 固定 / 缓推 / 环绕 / 手持；平均镜长；切点位置 | 一镜写多个运镜 |
| **③ 光线** | 方向（顺/侧/侧逆/顶/底）、硬度、光比、时段 | 只写"光线很美" |
| **④ 色彩与材质** | 主色调关系、饱和度、胶片模拟、材质质感 | 只写"色调高级" |
| **⑤ 声音** | 主体音效 / 环境音 / 静默节点 / 有无配乐 | 只写"配点音乐" |

> 与 `lens-grammar.md` 的七维的区别：**七维是"每个镜头必须填什么"，五轴是"调性怎么决定那七维填什么"。**
> 七维是填空题，五轴是判分标准。

---

## 三、调性反查表（用户口头语 → 坐标）

用户说的话往往不是他真正要的。**先翻译意图，再落参数。**

| 用户说 | 真正要的是 | ①构图 | ②运镜节奏 | ③光线 | ④色彩材质 | ⑤声音 |
|---|---|---|---|---|---|---|
| **"高级感"** | 克制、稀缺、不解释 | 大留白（≥50% 空），主体占比小 | 固定或极缓推；镜长 ≥3s | 硬朗侧逆光勾边，光比大 | 低饱和单色系，1 种主材质 | 静默为主，几乎无配乐 |
| **"有质感"** | 材质可触摸 | 特写 / 大特写，主体占满 | 固定 | 侧逆光，光比 1:4 以上 | 胶片模拟（Eterna / 250D），高细节 | 材质拟音（布料/金属/纸张） |
| **"干净"** | 信息少、秩序感 | 大留白 + 少元素，对称或三分 | 固定 | 均匀柔光，光比 ≈1:1 | 白 / 浅灰 / 单色，高调 | 单一环境音，无配乐 |
| **"治愈"** | 安全、暖、慢 | 中景为主，人物居中 | 缓推 / 固定；镜长 4–6s | 暖侧光 3200–4000K，柔 | 暖白调，低对比，低饱和 | 自然环境音 + 静默，轻柔配乐可 |
| **"很燃"** | 冲击、加速 | 中近景 + 低角度仰拍，主体大 | 快切；单镜 1–2s；甩镜点缀 | 硬光高对比，逆光剪影 | 高饱和 / 青橙对比 | 强音效 + 冲击前静默 + 鼓点 |
| **"大片感"** | 体量、纵深 | 大远景开场 → 人物远景（比重悬殊） | 缓推 / 升降 / 环绕 | 黄金时刻或冷调大光比 | 电影胶片模拟，青橙或冷暖分区 | 低频环境音 + 空间回响 |
| **"文艺"** | 疏离、留白、不解释 | 大留白，人物偏置，背对镜头 | 固定 / 极缓；镜长 ≥5s | 自然光，柔和侧光 | 低饱和，冷灰绿 | 环境音为主，无配乐 |
| **"真实"** | 不摆拍 | 中远景为主，构图不完美 | 手持轻微晃动 / 跟拍 | 自然光，不打光 | 无明显调色，颗粒 | 现场收音，保留杂音 |
| **"未来科技"** | 秩序、体量、精准 | 大留白 + 强对称，几何线条 | 环绕 / 升降；剪辑对鼓点 | 冷光 + 单点亮色源 | 深蓝冷底 + 单点亮色 | 电子音效 + 低频 |
| **"国潮"** | 东方审美进现代场景 | 材质微距 + 器物居中 | 慢节奏，缓推 | 自然光，柔和 | 红金 / 青瓷，低饱和 | 传统乐器点缀 + 环境音 |

**要避开的（反向坐标）**：

| 想避免的感觉 | 通常是这几项做错了 |
|---|---|
| 廉价 / 广告感重 | 高饱和 + 元素堆叠 + 影棚平光 + 满屏配乐 |
| 假 / 摆拍感 | 完美对称 + 影棚打光 + 过精致的动作 |
| 土 | "很燃"的节奏配了高饱和堆叠元素（燃的元素对了，色彩错了） |
| 空 / 记不住 | 全片平均用力，没有唯一视觉高潮 |
| 拖沓 | 镜长过平均值 + 在动作完成后才切 |

## 四、落地三步

1. **认调性**：从用户的话里认出**一个**（不是一个）核心调性词——"又高级又燃"不存在，让用户选一个
2. **查坐标**：查第三节拿到 5 轴的初步取值
3. **落到分镜表**：把 5 轴取值填进七维，逐镜保持一致；**同一支片子里 5 轴取值不能中途变**

> 判据：如果分镜表第 5 镜的光线/色彩跟第 1 镜取值不同，调性就断了——这就是"调性散掉"的技术定义。

---

## 五、两条铁律

- **调性词不进提示词正文。** "高级感""治愈""很燃"只用来查表，写进 prompt 的是查出来的参数。
- **调性决定的是"取舍"，不是"加法"。** 比如"高级感"的核心是**限制**（一种材质、一个高潮、大留白），不是加更多元素。**加元素永远拍不出高级感。**

---

## 六、力度调性坐标（动作片专用）

动作戏的调性不是风格，是**力度**。同一个四拍结构，力度调性不同，5 轴取值完全不同。

| 力度调性 | ①构图与景别 | ②运镜与节奏 | ③光线 | ④色彩材质 | ⑤声音 |
|---|---|---|---|---|---|
| **狠辣** | 低角度仰拍，中近景，主体大 | 短镜（≤1.5s），一镜一拍，hit-stop 定格 | 硬光高对比，侧逆光勾边 | 青灰底 + 暖血色点缀，低饱和 | **无配乐**，只有打击音 + 环境回响；冲击前静默 |
| **凌厉** | 中景，构图紧凑不留白 | **极短镜（<1s）**，whip pan 转场 | 冷调硬光，高光溢出 | 冷调，高对比 | 破空声、金属锐响；无低频 |
| **干净利落** | 中景，主体居中，构图整齐 | 节奏**均匀**有力，单镜 1–2s，不花哨 | 均匀侧光，光比中等 | 正常饱和度，**无血渍** | 干净打击音 + 明确节奏；无环境杂音 |
| **悲壮** | 大远景与特写**交替**，体量悬殊 | 慢一档（2–4s）；结局镜定格长 | 暗调 + 逆光剪影 | 低饱和冷调，去色倾向 | 低频 + 长回响；**允许配乐**（唯一的例外） |
| **压迫感** | 广角仰拍 + **前景遮挡**，低机位贴近 | 镜长略长（3–4s），缓慢逼近 | 低照度，大量阴影 | 脏灰冷调，高对比 | 持续低频轰鸣 + 静默交替 |
| **癫狂** | 荷兰角，手持大幅晃动，构图失衡 | 快切 + 跳切，节奏不规则 | 高对比，光斑闪烁 | 饱和偏高，色彩不统一 | 音效杂乱、叠加、失真 |

### 用法

1. 先定这场打戏的力度（**一个**，不要两个）
2. 查表拿 5 轴取值，填进分镜表与逐镜 prompt
3. 四拍内部保持一致；**只在「结果」拍可以短暂破格**（比如狠辣里结果拍突然变安静 → 反衬更狠）

### 力度 ↔ 四拍的关系

| 拍 | 参数倾向 |
|---|---|
| 预备 | 蓄力：镜长最长、构图最稳、声音最少（静默起势） |
| 冲击 | 爆发：镜最短、光比最大、声音最满 + **冲击前静默** |
| 结果 | 反馈：镜长回中、色彩最冷或最暖（定调性走向） |
| 反应 | 余势：构图最失衡、声音收尾、留白出现 |

> **力度感不来自形容词，来自"静—爆"的落差。** 全片一直很响 = 不响。冲击前那 0.2 秒的静默，比任何音效都值钱。

## 七、超现实调性坐标（奇幻 / 修仙 / 赛博专用）

力度调性解决"多狠"，超现实调性解决"**是什么性质的力量**"。同一个瞬移，仙气、霸道、诡谲的 5 轴取值完全不同。

| 超现实调性 | ①构图与景别 | ②运镜与节奏 | ③光线 | ④色彩材质 | ⑤声音 |
|---|---|---|---|---|---|
| **仙气 / 空灵** | 大远景留白，主体偏小，常置画面三分点 | 极慢（4–6s），几乎无运镜；升格大量使用 | 柔光、逆光、光晕扩散 | 青白、月白、淡金；**光效稀疏细密** | 风铃、箫、远处鹤唳；留白多 |
| **飘逸 / 写意** | 中景，人物常带衣摆与长发动态 | 缓跟 + 停顿；慢快慢节奏 | 侧逆光勾边，光从背后 | 水墨灰 + 一抹亮色（朱红/石青） | 衣袂破风、竹叶沙沙 |
| **霸道 / 碾压** | 低角度仰拍 + 前景遮挡，主体巨大 | 慢起（蓄力）→ 骤停（命中）；镜长对比极大 | 低照度 + 顶部硬光，压暗四周 | 黑 + 金/赤；**气旋浓密厚重** | 低频轰鸣、地面闷响、金属共振 |
| **诡谲 / 阴冷** | 荷兰角，构图失衡，主体常被切边 | 不规则，跳切 + 突然静止 | 顶光或底光，阴影反常 | 墨绿、紫黑、尸白；**光效偏绿或冷紫** | 指甲刮擦、湿黏物、低频不和谐音 |
| **暴烈 / 炸裂** | 中近景，主体大，画面满 | 极短镜（<1s）+ 甩镜；节奏密集 | 高对比硬光，光斑爆闪 | 高饱和，冷暖对撞强烈 | 密集爆响、碎裂、失真人声 |
| **神圣 / 庄严** | 对称构图，主体居中，广角 | 缓慢推近或静止；几乎不切 | 顶光/背光，轮廓发光 | 白金、纯白；**光效呈放射状** | 钟鸣、合唱、长回响 |

### 三条用法

1. **先定性质，再定力度。** 一场打戏 = 一个超现实调性 + 一个力度调性（如"霸道 + 压迫感"）。两个调性不要都选超现实的。
2. **光效的"量"由调性决定，不由情绪决定。** 仙气要**稀**（稀疏细密），霸道要**厚**（浓密厚重），暴烈要**炸**（放射状）。这是最容易被忽略的一条——想加气氛就加光效，结果是光污染。
3. **调性决定"取舍"不是"加法"**（铁律，全系列一致）。仙气的空灵感来自**留白和慢**，不是来自加更多光点。

> 配合 `supernatural-fight.md` 的"特效不能盖住动作"使用：**调性越仙，越要给动作留干净的空间**；调性越暴烈，越要靠"静—爆"落差而不是全程高响。
