# 概念转译法（Concept → Executable）

> 这份文件解决两个问题：
> ① 用户说的感受词（帅气 / 炸裂 / 满屏）怎么变成模型能执行的指令；
> ② **专业设计概念（剪辑、节奏、轴线、调度）到底该写在哪里** —— 哪些能进单镜提示词，哪些绝对不能。

---

## 为什么需要这一层

给 AI 视频模型写提示词时，用户常会说"要帅气""要炸裂""要满屏"。但：

- 直接把"帅气""炸裂"写进提示词 → 模型要么忽略，要么随机发挥，等于浪费预算。
- 完全禁止这些词 → 用户的创作意图丢失，画面变成 bland 的平均审美。

**解法**：把每个感受词翻译成模型能执行的「五类电影元件」，让意图不丢、废词不生。

---

## 一、模型能读懂什么、读不懂什么

判断一个词能不能进提示词，先过这张表：

| 层 | 内容 | 例子 | 处理 |
|---|---|---|---|
| **✅ 能懂** | 具体主体、身体部位、动作动词、方向、具体量、景别角度、光线、材质、物理结果 | "右肘撞在对方右肋，对方上半身向左侧弯，退了两步" | 直接用 |
| **⚠️ 半懂** | 常见摄影/运镜词（主流模型多数认）、胶片名、焦段 | "低角度仰拍""缓推""85mm 浅景深""Fuji Eterna" | 可用，但**旁边补一句自然语言描述**兜底 |
| **❌ 不懂** | 剪辑概念、抽象观感、学术术语、情绪形容词、抽象结果 | "匹配剪辑""蒙太奇""节奏感强""史诗""渐入佳境""他很强" | **禁止进 prompt** |

**一句话口诀：**

> **能写成"谁·做什么·朝哪·停在何处·结果是什么"的，模型就能读；
> 只能写成"感觉怎样"的，模型读不了。**

## 二、专业设计的分流：镜间 vs 镜内 ⭐

**这是最容易出错、也最能体现专业度的一条。**

写动作戏时，很多专业设计是**镜与镜之间**的关系，根本不属于任何单个镜头。把它们写进单镜提示词，模型完全无法理解——因为**一镜就是一镜，它内部没有"剪辑"这回事**。

### 分流表

| 专业设计 | 属于 | 正确落点 | ❌ 绝不能写进单镜 prompt |
|---|---|---|---|
| 动作匹配剪辑（Cutting on Action） | **镜间** | 分镜表的镜序 + 切点说明 | "cutting on action"、"在动作中段切" |
| 快剪 / 剪辑率 | **镜间** | 分镜表的镜长列 | "快速剪辑"、"多角度切换" |
| 同一击重复展示（两个角度背靠背） | **镜间** | 分镜表里排两个镜 | "同一动作演两遍" |
| 呼吸点 / 节奏弧线 | **镜间** | 把"停顿"单独排成一镜 | "加一个停顿"、"调整节奏" |
| 外部变量介入（抛武器等） | **镜间** | 单独一镜承载这个事件 | "突然出现一根棍子打断打斗" |
| 轴线 / 方位关系 | **镜间** | 分镜表的「方位」列 | "保持 180° 轴线"、"不要跳轴" |
| 匹配剪辑 / 形状剪辑 / 声音衔接 | **镜间** | 分镜表的「转场」列 | "用匹配剪辑转场" |
| **主体动作（含身体部位、方向、停点）** | 镜内 | ✅ **prompt 的「主体动作」段** | — |
| **景别 / 角度 / 单个运镜** | 镜内 | ✅ prompt | — |
| **光线 / 色彩 / 画幅时长** | 镜内 | ✅ prompt | — |
| **物理反馈（形变 / 碎屑 / 位移）** | 镜内 | ✅ prompt | — |
| **声音（音效 / 环境音 / 静默）** | 镜内 | ✅ prompt | — |

### 判据

> **一句话问自己：这个东西"看得到"吗？**
> ① 它在某一帧画面上看得到 → **镜内**，进 prompt
> ② 它只在"两颗镜头接起来"时才存在（切点、节奏、轴线、重复）→ **镜间**，进分镜表
>
> 剪辑不是拍出来的，是剪出来的。**让模型"拍"一个剪辑动作，等于让它往画面里画一个剪映图标。**

## 三、五类可执行元件

任何观感词都只能从下面五类里找落点，找不到落点的词就是"空泛废词"，直接禁：

1. **镜头元件** — 焦段 / 景别 / 角度
2. **构图元件** — 主体占比 / 留白 / 纵深
3. **运镜元件** — 推拉摇移跟 + 速度曲线
4. **光线元件** — 方向 / 硬度 / 色温
5. **物理反馈元件** — 碎屑 / 形变 / 余震 / 模糊

---

## 四、观感词转译表（核心资产）

| 观感词 | 转译为可执行元件（落到提示词里的内容） |
|--------|--------------------------------------|
| **长镜头** | 单镜连续≥10秒；机位不切；运镜维持连贯(跟/移)；用遮挡或甩镜做软过渡避免硬切 |
| **满屏** | 主体占画面≥75%；顶天立地构图；边缘切到肩/发外；压缩留白制造压迫 |
| **帅气** | 低角度英雄镜(15–25°仰)；侧逆光勾边；姿态设计(单膝/回眸/甩衣摆)；发丝衣摆慢动作 |
| **炸裂** | 冲击帧定格1–2帧(hit-stop)；径向模糊；碎屑向外飞溅；镜头微后坐 |
| **透视** | 广角(≈24mm等效)畸变；引导线构图；前景虚化；主体由远及近纵深调度 |
| **冲击帧** | 动作峰值瞬间定格；径向/速度模糊；粒子/水花定格；音效同步重音 |
| **重** | 承受者位移量（退几步/滑多远）；环境破坏（地面裂/墙碎）；镜头一次短震 |
| **快** | 起手到命中的动作路径要短；不给中间过程；甩镜或径向模糊 |
| **狠** | 攻击直指要害部位；收招不回收；对方失去平衡或倒地 |
| **乱**（混战） | 单人镜交替 + 镜头轻微手持；环境元素被波及；不用两人同框微操 |

### 超现实词（奇幻 / 超能力 / 修仙 / 赛博）

这类词的共同点：**它们描述的都是"不连续"或"超物理"，必须先给一个可见的中间态**。完整方法与可复制 prompt 见 `supernatural-fight.md`。

| 观感词 | 转译为可执行元件 |
|--------|----------------------|
| **瞬移 / 闪现** | 三段式：起点态 → **可见过渡态**（光尘消散聚合 / 冲击气浪 / 残影拖尾 / 光烟载体）→ 终点态；**机位固定、起点与终点同框** |
| **分身 / 连闪** | 单镜最多两段；≥3 段拆镜。或"同框多残影"：3–4 个残影 + 约 30% 不透明 + 各自不同姿态 + 最右为清晰实体 |
| **超高速** | 极短路径 + 大动态模糊（**只写两个端点**，中间交给模糊）；或甩镜；**必须配一个"静"的参照物**（静止的对手 / 悬停的雨） |
| **升格（慢动作）** | `慢动作` + **点名慢下来看什么**（停点 / 细节 / 余波）；一镜只放一个简单动作 |
| **变速（快→慢）** | **镜间，不进 prompt**：拆成两镜（快段约 1s + 慢段 3–4s），或生成正常速度后走后期速度曲线 |
| **剑气 / 罡风 / 法术** | 落成**可见介质**：定向光带 / 环绕气流 / 流动符文；带过之处必须有环境反应（瓦片掀起、尘土飞扬） |

### 氛围词（环境氛围层）

氛围词描述的是**环境与情绪**，不是主体。它们全部要展开成环境元件，写法与崩坏度设计见 `environment-atmosphere.md`。

| 氛围词 | 转译为环境元件 |
|--------|----------------------|
| **压抑** | 浓雾（只遮环境不遮主体）+ 低照度 + 单光源 + 无风 + 尘埃悬浮 |
| **肃杀** | 雨夜 + 无风 + 远处闷雷 + 水面静止 |
| **史诗感** | 大远景 + 低角度云 + 逆光剪影 + 风 |
| **诡谲** | 顶光或底光 + 影子方向反常 + 雾贴地不贴人 |
| **苍凉** | 黄昏逆光 + 长影 + 稀疏植被 + 风沙 |
| **窒息感** | 封闭空间 + 尘埃悬浮 + 单光源 + 无环境音 |
| **张力临界** | 一切静止 + 只有一处微动（灯火将熄未熄 / 水将滴未滴） |
| **孤独 / 对峙** | 大远景 + 主体极小 + 大量留白 + 风 |

> 氛围词**不进 prompt 正文**，展开成上面的环境元件。另外环境必须按「静 → 炸 → 余波 → 归位」参与四拍——它是力度落差的一半来源。

## 五、专业设计的正确翻译（正反例）

专业判断力要保留，但必须翻译成模型能解析的物理事实。**左边是想表达的，右边是能生效的。**

| 想表达 | ❌ 无效写法 | ✅ 有效写法 |
|---|---|---|
| 动作有力度 | "他重重一击" | "拳撞在前臂上，镜头在接触点短震一次，对方肩膀向右后方偏转，鞋底擦过积水滑出半步" |
| 招式清晰 | "他出剑攻击" | "手腕内旋，剑尖沿对角线切入对方左肋" |
| 攻击有终点 | "剑刺向敌人" | "剑尖停在对方胸前三寸，衣料凹陷但没有刺穿" |
| 身高差 | "两人对战" | "190cm 的重甲战士挥刀下劈，160cm 的对手侧身闪避，两人头顶高度差明显" |
| 光影有立体感 | "打斗场景，电影感" | "侧光，光源在角色右侧，阴影覆盖左半张脸" |
| 有实在感 | "人物站在地面" | "赤足踩在潮湿石板上，脚底与石缝交界处有阴影" |
| 表情有情绪 | "他非常愤怒" | "牙关咬紧，鼻翼张开，额头青筋凸起" |
| 环境参与打斗 | "激烈的打斗场面" | "拳锋擦过墙面，砖粉簌簌落下；他撞在长桌上，桌上的碗碟被震得跳起" |
| 有节奏停顿 | "加一个停顿" | （**镜间概念**）把停顿单独排成一镜："两人分开站定，相距三米，胸口起伏，对视" |
| 招式有性格 | "他的招式很克制" | "他抬手止住对方，指尖停在对方咽喉前一寸，随后收回" |

## 六、三个把 AI 短板变成手法的技巧

这三条都是**主动绕开模型最弱的能力**，同时画面反而更好：

### 1. 给动作一个"停点"

模型对"接触瞬间"的物理处理最差。**让动作停在接触之前，或给出精确的终结位置**：

> ⚠️ "他一拳打在对方脸上"（最容易崩，模型要生成接触形变）
> ✅ "拳头停在距对方面部一掌宽处，对方的头发被拳风带起"（更稳，且有力量暗示）
> ✅ "拳击中对方前臂，前臂横挡在胸前，两人同时定住半秒"（有接触但接触面简单）

**这不是回避，是"含蓄的暴力"——院线动作戏同样大量使用留白与遮挡。**

### 2. 姿态链（把连续动作拆成关键姿态）

模型的生成粒度是**帧**，不是动作。给它"打出一套组合拳"这种两秒整段描述，它只会压成一个模糊特征，动作糊成一团。

**做法**：把一个连续动作拆成 **3–5 个清晰的关键姿态**，姿态之间让模型自己补过渡。

```
❌ "他打出一套组合拳"
✅ "起势：右拳收在腰侧，肩部后倾 →
   出拳：右拳自下而上划出，身体前压 →
   命中：拳撞在对方前臂上，双方同时定住 →
   收势：他左脚踏前半步，重心落到前脚"
```

> 与「四拍拆解」的关系：**四拍拆解是镜头级**（一个镜头放一拍），**姿态链是镜内级**（一个镜头内部的动作分解）。两者配合使用，不冲突。

### 3. 力量证据外部化

不要写"打得很重"，写**环境和承受者的反应**（详见 `fight-design.md` 第五节）：
> ✅ "他被击中后撞翻了身后的木架，木板散落一地，灰尘扬起"

**放在承受者与环境上，比放在接触点上稳得多。**

## 七、自然语言写法规范

写进 prompt 的句子，遵守这 6 条：

| # | 规则 | 反例 → 正例 |
|---|---|---|
| 1 | **动词 + 身体部位 + 方向 + 停点** | "他攻击" → "他右拳自下而上打向对方下颌，停在对方下颌前" |
| 2 | **一次一个动作** | "他出拳同时转身踢腿" → 拆两镜 |
| 3 | **不用名词化术语** | "进行了打击" → "击中"；"完成了闪避" → "侧身让开" |
| 4 | **给具体量** | "退了很远" → "退了三步"；"很快" → "一眨眼" |
| 5 | **禁止顺序连接词** | "然后""接着""再"——出现即说明你在一个镜头里塞了两个动作，该拆 |
| 6 | **不用评价性词汇** | "打得很帅" → 见第四、五节转译 |

### 关于「句首顺序」的一个待验证分歧 ⚠️

本 skill 的既定铁律是：

```
主体动作 → 景别角度 → 单个运镜 → 光线 → 色彩 → 画幅+时长 → 声音
```

（依据：模型对句首内容权重最高，主体必须最前。）

但也有实操经验主张**先写镜头再写动作**，理由是"镜头运动方式决定时空坐标系，先定机位模型才知道动作从哪个视角展开"，且很多翻车案例是"打着打着视角从中景突然变成俯拍大远景"。

**这两条不必然冲突**，但优先级需要实测确认。**可执行的兼容方案**：

1. 主体动作仍放**句首**（保住主体清晰）
2. 镜头信息**紧跟其后且写全**（景别 + 角度 + 运镜一个不少）
3. 若出现"视角漂移"（同一镜内角度乱变），**试一个变体**：把景别角度提到句首，主体动作放第二段，两版对比抽卡结果

> 建议用同一条分镜、同一参数各出 4 条，比"视角漂移率"和"主体清晰度"。**哪版稳就用哪版，并把结论回写到本文件。**

## 八、转译规则（写进导演提示词【规格】的那条）

```
概念转译规则：我提到的观感词（帅气/炸裂/满屏/长镜头/透视/冲击帧等）禁止直接写进
提示词正文，必须展开成「镜头+构图+运镜+光线+物理反馈」五类元件后再组装。
直接写原词算不合格输出。

模型语言规则：禁止把「镜间」概念写进单镜提示词（剪辑手法/快剪/匹配剪辑/轴线/节奏调整/
同一动作重复展示），这些只能体现在分镜表的镜序与切点里。单镜提示词只写镜内可见的东西。
```

## 九、如何新增一个观感词

实测或用户提出表外词时，按这个模板补一行：

```
[新词]：[镜头元件]；[构图元件]；[运镜元件]；[光线元件]；[物理反馈元件]
```

判断标准：
- 能从五类里找到**至少两类**具体落点 → 收进表，可用。
- 五类都落不出具体元件（如"高级感""视觉盛宴"） → 归入禁词，不收。

## 十、禁词清单

### ① 无对应技法的空词（纯占预算）

电影感、史诗、震撼、极致、沉浸式、视觉盛宴、高级感、张力十足。

> 这类词不产出任何画面指令，只会挤占提示词预算。

### ② 镜间概念（写进单镜 prompt = 无效）

快速剪辑、多角度切换、匹配剪辑、蒙太奇、跳切、叠化、节奏感、镜头语言丰富、保持轴线。

### ③ 抽象结果与情绪评价

他很强、打得很激烈、气氛紧张、渐入佳境、势不可挡、眼花缭乱。

> ②③ 不是"坏词"，是**放错了地方**：② 属于分镜表，③ 属于你自己想清楚的事，都不属于单镜 prompt。

### ④ 超现实的概念词与抽象功（写进单镜 prompt = 无效）

**瞬移、闪现、空间跳跃、分身术**（概念词，模型不认识，必须转成三段式可见描写）、
**变速 / speed ramp**（属镜间）、
**内力、真气、无形剑气、气场、气势**（抽象，没有画面形态）。

> **特别注意 `凭空出现`**：它不是"不够好"的写法，而是**描述了一个画面错误**。正确写法是给出现/消失一个载体——"从光尘中凝聚成人形""化作一团青烟散开"。建议直接把 `凭空出现 / 生硬切镜` 写进负面词。
