# 多人打斗设计层：一对多、围攻与混战

> 本 skill 的「一攻一应」六要素是**双人模型**。本文件把它扩展到多人。
> `fight-design.md` 讲两个人在哪儿打、怎么打；这里讲**主角同时要对付多个人的时候**。

---

## 零、核心认知

实拍多人打斗崩 = **混乱**（不知道主角在打谁）。
AI 多人打斗崩 = **穿模 + 敌人凭空消失**。

**根因相同：观众和模型都同时处理不了多个精确交互。**

### 解法

**把多人打斗设计成"多个单人打斗的交替"，再加一个"全场位置图"。**

```
不是：主角同时对付三个人（模型必崩）
而是：主角 vs A（完整）→ 主角 vs B（完整）→ 主角破圈（移动）
      + 每一拍都写清「其他人在做什么」
```

**最后一句话是多人打斗的命门**：漏掉"其他人在做什么"，其他敌人就会在画面上凭空消失——这是多人戏最高频的投诉。

### 长尾类型怎么归类（避免以为没覆盖）

本文件已覆盖的常见与长尾多人情境，按需对号入座，不要另起一套逻辑：

| 类型 | 归入本文件哪一处 |
|---|---|
| 车轮战 / 逐个击破 | 第三节「接力型」结构（A 打完 B 上，天然就是车轮） |
| 柔术 / 摔跤 / 缠抱 | 第七节「地面技 / 擒抱」 |
| 马战 / 骑乘载具打斗 | 第九节「追车追逐」的运动+接触逻辑 + 第七节的"只拍起手与落地两端" |
| 跑酷 / 借环境移动 | 第九节「追车 / 追逐 / 跑酷」 |
| 软兵器（鞭 / 绳） / 长枪 | `weapon-design.md` 的对应武器表（节奏指纹与 AI 崩点） |
| 围攻但不同攻 | 第五节「围攻型」的正确做法（同时逼近、轮流攻击） |

> 规律：只要涉及"多个活人同时动"，都先走本节「威胁分级 + 一镜只拍主角 vs 一人」两根铁律，再套具体类型的细节。

## 一、威胁分级（同一时刻只让一个主要威胁成立）

| 级 | 角色 | 戏份 | 画面状态 |
|---|---|---|---|
| **① 主敌** | 与主角实力相当的那个 | 完整的一攻一应 | 清晰、活跃、占画面主要位置 |
| **② 副敌** | 凑数 / 牵制的 | 只给"切入动作"，不给完整交互 | 半清晰、在画面边缘或次要位置 |
| **③ 压阵** | 头目 / 远程 / 观望的 | 不动，或只缓慢移动 | 静止、剪影、远景里的小点 |

> **纪律：主角每一拍只对付一个人。** 这不是偷懒，是院线做法——《一代宗师》里叶问打一群人，也是一对一交替完成的。
>
> **同屏最多两个活人。** 三个以上同框且都在动 = AI 必崩（观众也看不懂）。

---

## 二、方位图（俯视，方位即信息）

打多人的第一件事：**画一张俯视图**，标出主角与每个敌人的方位。

- 敌人必须分布在主角的**不同方位**（左前 / 右前 / 正后），不要挤在一侧
- **方位本身就是叙事**：正后方的敌人 = 主角不知道的威胁 = 悬念；左右两侧 = 被夹击 = 压迫
- 分镜表维护「方位」列（本 skill 已有），**多人时这一列从"建议"变成"必填"**

> 可复制的开场镜：
> "大全景俯拍，主角站在空地中央，两名敌人分别位于画面左前与右前，第三人静止在主角正后方的暗处"

> **多人开场要同时满足两件事**：本文件的「俯视方位图 + 威胁分级」（让观众一眼读懂"被几个人、从哪个方向围"）与 `fight-design.md` 第十二节的「开场三件事 / 收场三件事」（教会地理、交代谁占优、给开打诱因；收场给静止的狼藉 + 代价可见）。方位图负责空间信息，第十二节负责头尾节奏——两者缺一不可，否则"围了很多人但不知道在看什么"。

## 三、多人版一攻一应表（六要素 + 第七列）

在 `fight-design.md` 第六节六要素基础上，**加第七列**：

| # | 要素 | 说明 |
|---|---|---|
| 1 | 谁发起 | 主角 or 某个敌人 |
| 2 | 攻击哪个部位 | 具体部位 |
| 3 | 接触还是落空 | 命中 / 闪避 / 格挡 |
| 4 | 对方如何回应 | 具体回应 |
| 5 | 位置如何变化 | 位移 |
| 6 | 给下一拍留的接口 | 未完成的动作 |
| **7** | **其他人在做什么** | **多人版的命门** |

**第 7 列的写法**——给每个人一个状态，不能省：

> ✅ "他从画面左跨步上前，右拳打向主敌右肋，主敌侧身让开、顺势用左肘撞他下颌，两人互换位置；**副敌在画面右侧抬刀未落，压阵者静止在背景暗处**"

> ❌ "他从画面左跨步上前，右拳打向主敌右肋"（副敌和压阵者消失了）

## 四、AI 拆镜四规则（多人戏专用）

| 规则 | 说明 |
|---|---|
| **1. 一镜只拍 主角 vs 一人** | 不要让两个敌人同时与主角接触。宁可拆成两镜 |
| **2. 两人同时攻击 → 拆两镜** | A 的刀先到、B 的拳后到，分两个镜头拍，用剪辑接出"同时"的错觉 |
| **3. 包围圈 → 单独成镜** | "被包围"本身是一个事件，给一个旋转 / 环视镜或主角转身镜，不要塞进打斗里 |
| **4. "即将切入"要写出姿态** | 写"副敌在画面右侧抬刀、左脚跨出半步"（可见姿态），不要写"其他人围攻上来"（抽象，模型会把人变没了） |

> **规则 1 是多人戏的根规则**，和双人戏的"一镜一拍"同级。违反它 = 穿模 + 敌人消失，双重崩。

## 五、三种多人结构（先选，再设计）

| 结构 | 设计 | 稳定性 | 适用 |
|---|---|---|---|
| **接力型** | A 打完 B 上，逐个击破 | ⭐⭐⭐ 最稳 | 首选，绝大多数场景 |
| **牵制型** | 一人缠斗（只逼近不接触），一人主攻 | ⭐⭐ 中 | 需要压迫感时 |
| **围攻型** | 多人同时逼近但**不同时攻击** | ⭐ 最危险 | 慎用；AI 几乎必崩 |

**围攻型的正确做法**：多人逼近是真的，但**攻击仍然轮流来**——镜头拍"三个人一起逼近"（远景，无接触），然后立刻切回"主角 vs 主敌"的单人对打。

---

## 六、混战（四人以上）

四人以上的混战，**放弃精确交互**，改用三种手段：

1. **远景 + 剪影**：只拍轮廓与倒下的方向，不拍招式
2. **只拍结果**：主角穿过人群，身后的人依次倒地（"倒地的方向"就是战斗过程）
3. **分组单人化**：把混战拆成几组单人打斗，用遮挡转场或甩镜接起来

> ❌ "一群人在混战，招式纷飞"（AI 会给你一团蠕动的人形）
> ✅ "大全景，主角从画面左走向右，三名敌人在他身后依次倒地，倒向各不相同"

---

## 七、地面技 / 擒抱 / 摔投（接触最密集，AI 最崩）

这是接触面积最大、持续时间最长的类型，也是 AI 最弱的。三条纪律：

1. **只拍起手与结果，不拍过程**——"他锁住对方脖颈" → 切 → "对方拍地求饶"。中间那段（两人纠缠滚动）交给观众脑补
2. **缠抱状态单独成镜且必须短**——两人抱在一起的镜头不要超过 1.5 秒
3. **摔投拍"离地"与"落地"两端**——中间抛物线过程模型容易糊；落地拍地面裂纹与扬尘（环境承接，见 `environment-atmosphere.md`）

> 这与"给动作一个停点"同源：**AI 处理不好"持续接触"，就把它拆成接触前 + 接触后。**

---

## 八、枪战 / 射击（特殊的一攻一应）

枪战的攻防单位不是"肢体接触"，是**射击与掩体**。

| 双人戏的要素 | 枪战的对应 |
|---|---|
| 谁发起 | 谁开枪 |
| 打哪个部位 | 命中哪里（或打在掩体上） |
| 接触还是落空 | 命中 / 未中 / 被掩体挡 |
| 对方如何回应 | 找掩体 / 还击 / 转移 |
| 位置如何变化 | 掩体之间的移动 |
| 给下一拍留的接口 | 弹匣 / 枪机状态 / 掩体被击穿 |

**AI 三规则**：

1. **射击者与目标不同框**——射手特写 + 弹着点特写，分两镜。同框枪战极易崩
2. **弹道不画出来**——写"弹着点"（掩体上的弹孔、地面的跳弹痕迹），不写"子弹飞行的轨迹"
3. **走位用掩体切换表达**——"他从掩体后闪出、开火、退回掩体后"，一镜一个动作

> 合规注意：实景枪械在多数短视频平台极度敏感，易触发审核；用光束 / 能量武器 / 剪影替代更稳妥。见 `compliance.md` 第二节。

---

## 九、追车 / 追逐 / 跑酷

这类戏的"一攻一应"退化为**速度与空间的交换**，重点是：

- **速度感靠参照物**：前景飞速后退的物体、被撞开的路障、地面的湿痕
- **一镜一个空间事件**：跳过某物 / 撞翻某物 / 落地翻滚，各自成镜
- **AI 友好做法**：车内拍演员表情（稳）+ 车外拍环境被波及（稳），少拍"车与人同时运动"（易糊）
- 飞行 / 浮空见 `supernatural-fight.md`

## 十、多人打斗自检清单

- [ ] 威胁分级已做：主敌 / 副敌 / 压阵各就各位，同屏最多两个活人
- [ ] 俯视方位图已画，敌人分布在主角不同方位，不是挤在一侧
- [ ] 一攻一应表有**第七列「其他人在做什么」**，且每一拍都写了
- [ ] 一镜只拍 主角 vs 一人；两人同时攻击已拆两镜
- [ ] "即将切入"写的是可见姿态（抬刀、跨步），不是"其他人围攻上来"
- [ ] 已选多人结构（接力 / 牵制 / 围攻），围攻型确认了"同时逼近但不同时攻击"
- [ ] 四人以上混战没有精确交互，只拍剪影 / 倒地方向 / 分组单人化
- [ ] 地面技只拍了起手与结果，缠抱镜 ≤1.5 秒
- [ ] 枪战射击者与目标不同框，弹道未写出
- [ ] 分镜表「方位」列多人场景下每一拍都填了
