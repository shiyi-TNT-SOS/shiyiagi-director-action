# 武器类型设计层：换武器 = 换一套参数

> `fight-design.md` 第二节只把"用什么打"当成开打前的一问。这份文件把它展开成设计表。
>
> **核心认知：武器决定攻击距离、动作幅度、画面可见性、AI 崩点四件事。同一个四拍结构，换武器全部参数都变。**

---

## 一、两套武器参数，别混

| 用途 | 管什么 | 出处 |
|---|---|---|
| **武器四要素**（类型 + 材质 + 长度 + 持握方式） | **一致性**——跨镜不变形 | `production.md` 6.4 |
| **本文件的类型设计表** | **设计**——这场打斗怎么打、镜头怎么给 | 本文 |

四要素每条 prompt 逐字复用；类型参数决定分镜结构。

---

## 二、武器类型设计表

| 武器 | 有效距离 | 动作特征 | 景别倾向 | 单镜时长 | AI 崩点 | 设计要点 |
|---|---|---|---|---|---|---|
| **空手**（拳脚肘膝） | 贴身 | 快速连续、幅度小、频率高 | 中近景、特写 | 1–2s | 手部最弱；接触点形变 | 停点 + 姿态链；力量证据放承受者 |
| **刀 / 剑** | 中距 | 划、刺、斩，有轨迹 | 中景 | 2–3s | 武器变形；手部 | 刀锋轨迹必须写；刃面反光可锁一致性 |
| **长棍 / 长枪** | 远距 | 扫、刺、大回旋 | 全景、纵深 | 3–4s | 武器弯曲变形；两端易出画 | 两端都要在画面内；用回旋制造全景冲击 |
| **双武器** | 近中 | 交替、不对称 | 中景 | 1–2s | **多手多肢（最高风险）** | 一镜只让一只手工作 |
| **暗器 / 投射** | 远距 | 极小动作发射 | 特写 + 目标反应 | <1s | 飞行轨迹易糊 | 只写发射与命中两端，中间不写 |
| **鞭 / 链 / 软兵器** | 中远 | 缠绕、甩击 | 中景 | 2–3s | **极易糊成一团** | 慎用；只拍起手与命中 |
| **枪械** | 远距 | 极小动作 | 特写 + 弹着点 | <1s | 手部；武器细节 | 射手与目标不同框（见 `multi-opponent-design.md` 第八节） |
| **钝器**（锤斧棒） | 近中 | 慢、重、蓄力明显 | 中景 | 2–3s | 接触点形变 | 蓄力拍长、命中拍短；环境破坏为主 |
| **异能 / 法术** | 任意 | 无实体 | 见 `supernatural-fight.md` | — | 光效盖人 | 小而准；只在起手与命中发光 |

---

## 三、武器的「节奏指纹」

不同武器的攻防频率完全不同——**这直接决定四拍的时长配比**。

| 武器 | 单招时长 | 四拍配比倾向 |
|---|---|---|
| 空手 | 1–2s | 预备短、冲击极短、反应短（快节奏） |
| 刀剑 | 2–3s | 均衡 |
| 长兵器 | 3–4s | 预备长（蓄力）、冲击短、反应长 |
| 钝器 | 2–3s | **预备最长**（举锤）、冲击极短 |
| 枪械 | <1s | **没有"预备拍"**，只有射击与反应 |

> **换武器不换配比 = 节奏错。** 长兵器用空手的 1–2 秒配比，会显得"挥不动"；钝器不给长蓄力，就显不出"重"。

---

## 四、武器在四拍中的角色

| 拍 | 武器角色 | 写法 |
|---|---|---|
| **预备** | 后引 / 蓄力 | 写武器的**角度与位置**（"刀身平举于肩后，刃朝左下"） |
| **冲击** | 划出轨迹 | 写武器的**路径**（"自右下向左上划出"），不只写动作 |
| **结果** | 震颤 / 脱手 / 入物 | 写武器的**余波**（"刀身插进地面，仍在震颤"） |
| **反应** | 对手的武器状态 | 写对手武器（"对方的刀脱手飞出，插入木板"） |

> **武器的轨迹必须写。** 双人戏里"谁打谁"靠肢体；有武器时"从哪来到哪去"靠武器轨迹。不写轨迹 = 观众不知道那一刀是怎么挥的。

---

## 五、武器与安全距离（设计约束）

武器的有效距离不同，**决定了两人该站多远**：

| 武器 | 建议间距 | 超出 / 不足的后果 |
|---|---|---|
| 空手 | 一臂 | 太远 = 打不到；太近 = 没有预备空间 |
| 刀剑 | 一臂半 到 两步 | 太近 = 没有挥剑空间，镜头显挤 |
| 长兵器 | 三 到 五步 | 太近 = 长兵器反而受限 |
| 枪械 | 十步以上或跨场景 | 太近 = 枪的优势没了 |

> **可利用的设计**：让强者用长兵器、被弱者近身——这是"被克制者胜"的经典写法（`supernatural-fight-design.md` 第二节的克制关系，同样适用于写实）。
>
> 可复制的近身转折镜：
> "他矮身前冲，切入长刀的内侧，刀锋从他头顶掠过劈空，他已是近身姿态"

## 六、武器一致性

见 `production.md` 6.4：武器单独出参考图（正侧两张）、固定描述串逐字复用、**武器被遮挡或出画后，下一镜必须重新交代它在哪**（打斗中"武器凭空消失"是高频投诉）。

---

## 七、武器选择速查（用户不知道用什么时）

| 用户要的感觉 | 推荐武器 |
|---|---|
| 干净利落 | 单刀 / 匕首 |
| 霸气碾压 | 长柄大刀 / 巨剑 |
| 飘逸写意 | 长剑 / 长棍 |
| 残酷真实 | 短刀 / 钝器 |
| 技巧型 | 双短兵器 / 长棍 |
| 压迫感 | 链锤 / 鞭 |

> 选定后回第二节查该武器的 AI 崩点与设计要点——**这一步最常被跳过，然后就在模型最弱的地方反复抽卡**。

---

## 八、自检清单

- [ ] 已按第二节查出该武器的 **AI 崩点**，并在提示词里主动绕开
- [ ] 四拍时长配比符合该武器的**节奏指纹**（长兵器 / 钝器给了长蓄力）
- [ ] 两人的间距符合该武器的**安全距离**
- [ ] 武器的**轨迹**写进了冲击拍（角度 + 路径），不只写动作
- [ ] 结果拍写了武器余波，反应拍写了对手的武器状态
- [ ] 武器描述串（类型 / 材质 / 长度 / 持握）跨镜逐字复用
- [ ] 武器出画后，下一镜重新交代了它的位置
- [ ] 双武器确认了"一镜只让一只手工作"
- [ ] 软兵器 / 暗器 / 枪械已按各自规则处理（只拍两端 / 不同框 / 不写弹道）
