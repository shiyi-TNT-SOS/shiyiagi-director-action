# 超现实打斗：瞬移 / 连闪 / 超高速 / 升格 的提示词写法

> 本文件解决 `fight-design.md` 没覆盖的一类：**奇幻武侠、超能力、赛博格斗里的"违反物理"的动作效果**。
> 写实打斗见 `fight-design.md`；这里处理"瞬移、多段连续瞬身、超高速攻击/移动、升格"这四类**单镜怎么写**。
>
> **先读 `supernatural-fight-design.md`（设计层）**——那一份解决"这场打斗本身怎么设计"（能力契约 / 克制关系 / 情报战四段式）。没有设计层，单镜写得再准也是一场"不知道谁为什么赢"的打戏。
>
> **一句话总纲：所有"不符合物理"的效果，都必须给它一个"可见的中间态"。**
> 不给中间态，模型就不知道该画什么，只会随机发挥——最常见的翻车是"人形糊掉""融化""凭空多出一个人"。

---

## 零、为什么这类效果天生难写

**"瞬移"的本质是空间不连续，而空间不连续在实拍里是靠"剪一刀"实现的——也就是镜间。**

但你想要的画面是"在**一段连续画面**里看到瞬移"，这就逼着模型在**镜内**表现一个**镜间**的效果。

```
实拍逻辑：A位置 ｜切一刀｜ B位置        （没有中间过程，观众自己脑补）
AI 要的效果：A位置 → ？ → B位置         （问号这一段，模型必须画出点什么）
```

**那个"？"就是过渡态。它必须可见，而且必须是你指定的。**
你不指定，模型就自己编——通常编成"融化""糊成一团""多长一个人"。

### 统一结构（所有超现实位移都套这个）

```
① 起点态（主体在场，姿态明确）
      ↓
② 过渡态（可见纹理：粒子 / 气浪 / 残影 / 光烟）← 提示词的重点全在这里
      ↓
③ 终点态（空位，或新位置 + 新姿态）
```

### 两条硬规则

| 规则 | 说明 |
|---|---|
| **机位固定 + 起点终点同框** | 只有同框，观众才能在一个画面里同时读到"他消失了"和"他到那儿了"。这是十字景框的逻辑（见 `fight-design.md` 第十节）。镜头一跟一甩，效果就散了。 |
| **禁止"凭空出现"** | "凭空出现"是画面错误的代名词。出现必须有载体：从光尘中凝聚、从黑雾里收束、从剑气里显形。这条建议直接写进负面词。 |

## 一、过渡态的四种可见载体

选一个即可，不要四个都用（会糊）。

### 1. 粒子消散 / 聚合（最通用，奇幻科幻都能用）

**要点**：写清 **方向 + 速度 + 密度** 三件事。

| 参数 | 慢（空灵/仙气） | 快（强横/暴烈） |
|---|---|---|
| 速度 | 缓慢飘散 | 瞬间炸开 |
| 密度 | 稀疏细密 | 密集厚重 |
| 方向 | 自下而上飘升 | 向外放射 |

> ✅ 可复制：
> 白衣剑客站在青石庭院正中，身形自下而上化为稀疏的白色光尘向上飘升，人已出现在五米外的石阶上，保持拔剑前的侧身姿态，原地只剩最后几缕光尘消散；固定机位，大全景，两个位置同框；冷蓝月光；青灰冷调；2.39:1 电影画幅 / 4秒；衣袂破风声与一声极轻的铃响，无背景配乐

### 2. 冲击气浪（最有力量感，适合强横角色）

**要点**：单帧消失 + 一圈**径向压力波** + 被波及的环境物。

> ✅ 可复制：
> 黑衣人在一瞬间从原地消失，原地留下一圈向外扩散的半透明气浪，气浪压弯四周杂草、掀起碎叶向外飞散，三米外他已单膝落地、一手撑地；固定机位，中景；硬光侧逆光勾边；冷调青灰；2.39:1 / 3秒；一声短促的破空闷响与草叶沙沙声

### 3. 残影拖尾（最"高速"，适合冲刺型瞬身）

**要点**：写清**残影数量 + 透明度 + 间隔 + 各自姿态**。数目 3–4 个最稳，透明度约 30%，间距越小越"快"。

> ✅ 可复制：
> 红衣女子从画面左侧冲向右侧，身后拖出三道依次变淡的红色残影，每道残影保持略微不同的前倾姿态、最靠近她的一道最深、最远的一道几乎透明，最右侧的实体最清晰；固定机位，全景；侧逆光；暖红调；2.39:1 / 3秒；连续三次短促的衣料摩擦声

### 4. 光 / 烟载体（中式奇幻首选，见第六节）

**要点**：把"位移"交给一个**可见的介质**——剑光、青烟、符箓光、罡风。

> ✅ 可复制：
> 青衣剑客站在原地，周身腾起一道环形剑气，人与剑气一同化作一道青色光带射向画面右侧，光带掠过之处屋檐瓦片被气劲掀起、碎瓦随光带拖出尾迹；固定机位，全景；冷调；2.39:1 / 3秒；一声清越的剑鸣由近及远

## 二、多段连续瞬身（连闪）

**先说结论：单镜最多连做两段。** 三段以上必须拆镜。

| 段数 | 做法 |
|---|---|
| **2 段** | 单镜可做：起点一个"正在消散的残影" + 终点一个实体 |
| **3 段及以上** | 两个方案，见下 |

### 方案 A：拆镜（推荐，最稳）

每段一个镜。每个镜只做"一次位移"，靠剪辑接成"连闪"的观感。

- 镜 1：起点态 + 开始消散
- 镜 2：中段位置显形（可只给局部，如一只脚落地、衣角入场）
- 镜 3：终点态 + 落定姿态
- **镜间关系（切点、节奏）只写在分镜表里，不进 prompt**

### 方案 B：同框多残影（一镜做出"三连闪"的观感）

这不是"三段时间"，而是**三个空间位置同时出现在一帧里**——像连拍叠印。所以它能进单镜。

**必须写清**：数量 / 排列方向 / 各自姿态 / 透明度递增 / 哪个是实体。

> ✅ 可复制：
> 同一画面内从左到右依次排列三个半透明的深色身影，姿态各不相同——最左一个上身左上挑、中间一个平刺、最右一个下沉下劈，三者的清晰度与不透明度自左向右递增，最右侧为完全清晰的人形实体，最左两个边缘略微透明发散；固定机位，全景；冷调侧光；2.39:1 / 3秒；三声依次递进的刀锋破空声

### 连闪的"延迟感"参数

想要"分身一个接一个出现"的观感，写**延迟**而不是"快速"：

```
3–4 个残影 + 约 30% 不透明度 + 每个比前一个延迟半个身位/半步
```

不要写"残影很多"——数量一多，模型会撕裂。可灵的 `motion blur intensity` 调高就会让快速挥动出现残影撕裂，这也是**残影要克制**的实证。

## 三、超高速攻击 / 移动（"快"怎么写）

**核心认知：「快」是比出来的，不是写出来的。**
你写"极快""光速"，模型没有参照系，只会把整体画面搞糊。

### 三个落点

| 落点 | 写法 | 适用 |
|---|---|---|
| **极短路径 + 大动态模糊** | 只写两个端点（腰侧 → 抵在胸前），中间交给运动模糊 | 出拳、刺击 |
| **甩镜（whip pan）** | 镜头快速横甩，画面拉出方向性模糊 | 空间转移、攻防切换 |
| **速度线 / 拖尾** | 攻击轨迹上拉出发光或灰色的速度线 | 奇幻、动漫感 |

### 关键技巧：给"快"配一个"静"

同一画面里必须有一个**不动或很慢的参照物**——静止的对手、缓慢飘落的叶子、悬停的雨滴。有对比，快才成立。

> ✅ 可复制（超高速出拳）：
> 他右拳自腰侧弹出，整条手臂拉成一道向前的运动模糊，拳锋已抵在对方胸前一寸，对方的衣料被拳风压出向内的褶皱、身体尚未做出反应；固定机位，中近景；硬侧逆光；2.39:1 电影画幅 / 1秒；一声短促的破风声

> 注意这个例子里"**对方尚未做出反应**"就是那个"静"——它是让"快"被读出来的关键。

## 四、升格（慢动作）

**升格 = 高速摄影 + 正常速度放映 = 慢动作。** 提示词里直接写 `慢动作` / `slow motion` 即可，模型认。

### 但慢动作的正确用法是"放大细节"，不是"变慢"

只写"慢动作"，模型会把整段都放慢，然后糊成一团。**必须点名"慢下来要看什么"**：

- 看**停顿**：拳停在胸前，衣料被拳风压出的褶皱慢慢回弹
- 看**细节**：剑尖震颤、被削断的发丝缓缓飘落、汗珠离开脸颊
- 看**余波**：尘埃缓缓落下、水花悬在半空尚未崩散

> ✅ 可复制：
> 慢动作，他的拳停在距对方胸口一寸处，对方的衣料被拳风压出向内的褶皱并缓缓回弹，一颗汗珠从对方脸颊缓慢脱离、悬在半空；固定机位，特写；硬侧逆光；2.39:1 / 3秒；低频闷响被拉长，无背景配乐

### 慢动作的三条纪律

1. **一个镜只放一个简单动作**——慢动作塞两个动作必糊
2. **主体动作幅度要小**——小动作在升格里信息量足够，大动作升格会蠕动
3. **若引擎支持，宁可生成正常速度再后期光流减速**——模型直出的慢动作常有肢体蠕动；后期用光流（如 DaVinci Speed Warp）减速往往更干净

## 五、变速（超快 ⇄ 升格，speed ramp）

**变速是时间轴上的处理 = 镜间 = 不能写进单镜 prompt。**
一镜之内只能"匀速快"或"匀速慢"，"先极快后极慢"在单镜里是无法指定的。

### 方案 A：拆两镜（适合需要清晰的两段）

```
镜 A（超快，1秒）：动作的"路径"——极短、大模糊
镜 B（升格，3秒）：动作的"结果"——停点、细节、余波
```

**切点选在动作峰值**（Cutting on Action），两镜的时间是"接续"关系，观众会自己脑补成一次变速。

> ✅ 镜 A：他右拳自腰侧弹出，整条手臂拉成一道向前的运动模糊，拳锋抵在对方胸前一寸；固定机位，中近景；**1秒**；短促破风声
> ✅ 镜 B：慢动作，拳停在对方胸前，衣料褶皱缓缓回弹，汗珠缓慢飞离；固定机位，特写；**3秒**；闷响拉长
> （**变速感来自两镜的时长对比 1s → 3s，不来自任何一句 prompt**）

### 方案 B：生成正常速度，后期变速（最可控，推荐）

1. 让模型生成一条 **4–6 秒的正常速度完整动作**
2. 在剪辑软件里用速度曲线做"快 → 慢 → 快"
3. 慢下来的那段用光流补帧

**为什么推荐**：模型直出变速几乎做不到，而且慢动作段容易糊；而"正常速度素材 + 后期速度曲线"是实拍电影做 speed ramp 的标准流程，可控性高一个量级。

## 六、奇幻武侠的特有语法

中式奇幻里，位移和超高速**都要靠一个可见的介质来"合理化"**，这个介质同时就是过渡态。

### 常用介质表

| 介质 | 视觉形态 | 适合 |
|---|---|---|
| **剑光 / 剑气** | 一道定向的锐利光带，带过之处有切割感 | 剑客、高手 |
| **青色/白色罡风** | 环绕身体的气流，掀起周围轻物 | 内功型 |
| **青烟 / 墨迹** | 人化为烟、烟中凝形；或如墨入水晕开 | 灵异、仙侠 |
| **符箓 / 光斑** | 贴身亮起的符文光圈，位移时拖出光尾 | 道法、法术 |
| **残影如影** | 黑色剪影状的残影，而非实体残影 | 刺客、暗影系 |

> ✅ 可复制（剑气位移 + 化身）：
> 白衣剑客原地凝神，周身腾起细密的白色剑气，身形随即散作一团白雾，白雾如箭般沿直线射向十米外，途中凝回人形、落地时衣袍尚未完全收束；固定机位，大全景，起点与终点同框；冷调月光；2.39:1 电影画幅 / 4秒；剑气破空声由近及远，尾音带轻微回响

### 奇幻语的禁词

| ❌ 不能写 | 为什么 | ✅ 改成 |
|---|---|---|
| 内力 / 真气 / 无形剑气 | 抽象，没有画面形态 | "周身腾起白色的气流" |
| 瞬移 / 闪现 / 空间跳跃 | 概念词，模型不认识 | 三段式：起点态 → 光尘/气浪/残影 → 终点态 |
| 身法快到看不清 | 抽象 + 等于让模型乱糊 | "整条手臂拉成一道向前的运动模糊" |
| 气场强大 / 气势惊人 | 情绪评价 | "脚下青石板自中心向四周裂开细纹" |
| 凭空出现 | 描述了一个画面错误 | "从光尘中凝聚成人形" |

## 七、参数与引擎注意事项

| 项目 | 做法 |
|---|---|
| **残影数量** | 3–4 个最稳；过多会撕裂（可灵 `motion blur intensity` 偏高时快动作会出残影撕裂） |
| **慢动作** | 直接写 `慢动作` / `slow motion`；若模型肢体蠕动，改生成正常速度 + 后期光流减速 |
| **流畅度** | 可灵可用 `keyframe density: high` 提升肢体流畅度；要定格感用低关键帧密度 |
| **负面词** | 写进负面词：`凭空出现 / 生硬切镜 / 物体突然冒出`——这是把"画面错误"挡在外面最直接的一条 |
| **时长** | 瞬移类单镜 3–4 秒足够；变速的"快段"压到 1 秒，"慢段"给 3–4 秒 |
| **画幅** | 仍是 2.39:1；**同框双位置**需要横画幅才有空间，竖屏改为纵向排列（起点在上、终点在下） |

> Seedance 2.5 的转场公式自带两条护栏——**禁止生硬切镜、禁止物体凭空出现**。这两条对超现实打斗同样适用，建议每次都写进负面词。

## 八、自检清单（超现实打斗专用）

- [ ] 每个"违反物理"的效果，都指定了**可见的过渡态**（粒子/气浪/残影/光烟），不是"瞬移"两个字带过
- [ ] 瞬移类镜头**机位固定**，起点与终点**同框**
- [ ] 多段连闪 ≤2 段在一镜；≥3 段已拆镜，或改用"同框多残影"
- [ ] 残影写了**数量 + 不透明度 + 间隔 + 各自姿态**，数量不超过 4
- [ ] "快"配了一个"静"的参照物（静止的对手 / 悬停的雨 / 缓慢飘落的叶）
- [ ] 慢动作点名了"要看什么"（停点 / 细节 / 余波），且一镜只放一个简单动作
- [ ] **变速（快→慢）没有写进单镜 prompt**，而是拆成了两镜或留待后期速度曲线
- [ ] 奇幻介质是**可见形态**（剑气光带 / 青烟 / 符箓光斑），没有出现内力/真气/无形这类抽象词
- [ ] 负面词里写了 `凭空出现 / 生硬切镜`，把画面错误挡在外面
- [ ] 竖屏版把"同框双位置"改成了**纵向排列**（上→下），没有硬塞横向
