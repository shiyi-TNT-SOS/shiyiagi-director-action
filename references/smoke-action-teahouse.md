# 行为冒烟示例（等级 2）· 茶馆一对一近身格斗

> 本文件是 `shiyiagi-director-action` 的可执行测试：用一个单回合近身格斗，跑通「第 2 步打斗设计 → 四拍拆解 → 逐镜提示词」全流程，产出具体可用的提示词，证明本 skill 能落地而非空话。

## 0. 测试场景

茶馆（木质方桌两张、暖黄吊灯）、壮年茶客 vs 年轻挑衅者（体型差小）、纯拳脚、调性「凌厉」、观感词「炸裂 / 冲击帧」、画幅 2.39:1、生成单元 4–10s。

## 1. 第 2 步 · 打斗设计（开打前想清楚）

- **力量对比**：壮年靠经验与重心（守）、青年靠蛮力（攻）；壮年弱点=年长反应略慢，青年弱点=破绽多。
- **空间**：两张方桌 + 条凳，唯一出口在右后门；无高度差，道具可借（茶壶、凳）。
- **体系**：港式表演型（感受=惊叹：技艺与编排）。
- **节奏弧**：1 个呼吸点（格挡后短暂对峙），无外部变量。

## 2. 四拍拆解（单回合）

| 拍 | 环境 | 内容 | 给下一拍的接口 |
|---|---|---|---|
| 预备 | 静 | 青年挥右直拳，壮年侧身闪 | 壮年右手已抓住青年手腕 |
| 冲击 | 炸 | 壮年借势反擒，拧臂下压 | 青年被带向桌沿 |
| 结果 | 余波 | 青年撞翻方桌，茶壶碎 | 壮年收势、呼吸 |
| 反应 | 归位 | 壮年松手、茶客惊散、静止狼藉 | — |

## 3. 逐镜提示词（七段顺序）

**镜 A（预备拍）**
> [壮年侧身闪过青年右直拳，右手扣住其腕] + [中近景·平视·微仰] + [固定机位轻微后拉] + [暖黄吊灯顶光，桌面高光] + [暖褐调，茶烟微升] + [2.39:1·生成 6s] + [茶馆环境底噪，拳风破空]

**镜 B（冲击拍）**
> [壮年借势反擒拧臂下压，青年失衡前倾] + [近景·低角度英雄镜] + [whip pan 甩向桌沿] + [顶光勾壮年肩线，青年脸入影] + [对比强化，桌面阴影] + [2.39:1·生成 5s] + [衣料摩擦 + 木桌吱呀]

## 4. 自检（关键项勾选）

- [x] 打斗设计表已出（力量对比/空间/体系/节奏），非直接跳四拍
- [x] 一攻一应表每拍含"给下一拍留的接口"
- [x] 环境列：静→炸→余波→归位，崩坏度单调上升，末镜静止狼藉
- [x] 无持续流体（茶烟短促）；去环境后主体动作仍成立
- [x] 单镜一拍，无"一镜连续打斗"
- [x] 提示词顺序：主体动作最前；生成单元 4–10s
- [x] 观感词"炸裂"已转译（hit-stop/径向模糊/碎屑），未裸写
- [x] 接触动作简单（扣腕/拧臂），无多人同框穿模

## 5. 结论

全流程产出设计表 + 四拍拆解 + 2 条可直接复制的逐镜提示词，关键自检通过。证明本 skill 在「单回合近身格斗」场景下可落地、可质检。反向对照：若跳过第 2 步，会直接产出"两人糊在一起抽搐"的废片。
