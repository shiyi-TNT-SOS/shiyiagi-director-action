# 打斗设计层：院线级动作戏怎么设计（以及怎么写成模型能读懂的提示词）

> 主模板与四拍拆解解决的是「怎么把打斗拆成镜头」。这份文件解决**更前面的一步：这场打斗本身怎么设计**。
> 院线级动作戏和"两个纸片人做广播体操"的差距，八成来自这一步，不是镜头。
>
> **本文件讲的是写实打斗（拳脚 / 兵器 / 追车）。奇幻武侠、超能力、修仙这类"违反物理"的效果（瞬移 / 分身 / 超高速 / 升格）见 `supernatural-fight.md`。**
>
> **本文件每一条设计，都紧跟一行「写进提示词怎么说」——因为最终要交给视频模型。**
> 影片名只用于你自己建立参照，**不要写进 prompt**（模型不认识片名，只会浪费预算）。

---

## 零、总纲：六个字

对袁和平动作设计有一个流传很广的概括，只有六个字：**「看得懂，看得爽」**。

- **看得懂** = 空间、方位、谁攻谁防、谁占优，观众任何时刻都能读出来
- **看得爽** = 力量、节奏、技艺，有明确的强弱变化与停顿时机

**这条同时是设计标准和提示词标准：模型也是观众。它"读不懂"的提示词，出来的画面观众也读不懂。**

所以本档所有设计，最终都要能落成「谁·做什么·朝哪·停在何处·结果是什么」这种模型能解析的句子。

## 一、开打前的四问（缺一个就别写分镜）

| 问 | 决定什么 | 是否写进提示词 |
|---|---|---|
| **为什么打**（赌注） | 投入程度、表情与力度上限 | 一般不进 prompt（影响的是设计选择） |
| **谁强谁弱**（力量对比） | 攻防关系：谁进攻、谁防守 | ✅ 进（写"以多打少 / 体格悬殊 / 一方明显占优"） |
| **用什么打**（拳脚 / 兵器 / 道具） | 招式库与空间需求 | ✅ 进（武器的固定描述串） |
| **打多久**（时长与节奏） | 段落切分与呼吸点数量 | 分镜表层面 |

### 力量对比：最容易被忽略、最影响观感的一条

两人一样强 = 平分秋色 = 没有戏剧性。三种基本关系，写法完全不同：

| 关系 | 设计要点 | 镜头倾向 | 提示词里的写法 |
|---|---|---|---|
| **以弱对强**（最常见） | 弱者靠技巧、环境、攻弱点取胜 | 低角度仰拍 + 急推，营造"险" | "他被迫后退三步，背抵住墙，退无可退" |
| **势均力敌** | 靠"来回"：你一招我一招 | 机位平衡，节奏最规整 | "他的直拳被格开，随即回敬一记摆拳，两人各退半步" |
| **压倒性** | 强者压制，弱者挣扎 | 压制性俯拍与仰拍交替，节奏一边倒 | "巨掌按住他肩膀向下压，他单膝跪地，青石板裂开" |

> **体型差必须写出来。** "两人对战"是无信息量写法；"190cm 的重甲战士挥刀下劈 vs 160cm 的对手侧身闪避"才是模型能解析的。差越大，画面冲突越强。

## 二、招式设计的四条原则

### 1. 用双方的优势互攻（不补短板）

袁和平设计《叶问外传》的核心方法：给主角配"势均力敌且相当有看头"的对手，**让双方各自的长处相撞**——泰拳手就打肘膝，咏春就打快而密的连击。

**写进提示词**：不要写"他打得很好"，写**具体的优势动作**。
> ❌ "他使出精湛的拳法"
> ✅ "他连续三次快速短拳击打对方腹部，手肘贴身不出肩"

### 2. 攻其弱点（攻击目标必须具体）

《叶问外传》里张晋身材矮小，就让他**专打对方右侧肋骨的旧伤**——"有逻辑且让观众看得懂"。

**写进提示词**：写出**打哪里**。
> ❌ "他一拳打向对手"
> ✅ "他侧身让开重拳，顺势用肘尖撞在对方右肋，对方上半身向左侧弯"

攻击目标具体化，顺带解决了 AI"两人糊成一团"的问题：**明确部位 = 明确画面**。

### 3. 道具延伸（环境是武器库）

《少年黄飞鸿之铁马骝》用杯子、茶壶、筷子**延伸手臂与腿的动能**。

**写进提示词**：道具必须在动作里**被使用**，不是背景。
> ✅ "他抓起铁锅挡在身前，刀刃在锅底劈出一道凹痕，他顺势把锅推向对方胸口"

⚠️ **AI 限制**：道具交互要简单（一挡 / 一推 / 一砸），不要"在狭小空间用筷子连打十招"。

### 4. 招式承载性格（同一招，不同打法）

袁和平最精妙的例子：同一个"标指"招式，张天志用它要命，叶问用它留手——高下不在招式，在**用力度和收招方式**。

**写进提示词**：用**力度**和**收招**表达性格。
> ✅ "他抬手止住对方，指尖停在对方咽喉前一寸，随后收回"（克制）
> ✅ "他一拳打穿对方防守，收拳时顺势带倒对方"（狠辣）

### 5. 招式名词化（一个词唤起一套动作）

武术术语是信息密度最高的招式语言："刺、撩、抹、截"四个字各是一整套可执行的动作路径，比"快速连击四下"高一个量级；"地堂平削"直接锁定了重心高度与剑的轨迹平面。

**写进提示词**：优先用具体招式动词；生僻或自造的招式名要**术语 + 路径双保险**（模型没见过的词，后面必须紧跟动作描述）：
> ✅ "一秒内倾泻出刺、撩、抹、截四连抵挡"
> ✅ "压低重心，长剑贴地横扫出一记地堂平削——剑尖始终离地一寸"
> ⚠️ 只写自造招式名不给路径 = 模型随机发挥，等于没写。

## 三、空间是打斗的一半（"房间逻辑"）

香港动作片打得清楚的根本原因：**先把场地教会观众，再开打。** 开场给一个能看清出口、桌台、楼梯、栏杆的镜头——之后每个动作都被读成"选择"，而不是噪音。

四条可执行规则：

1. **先交代地理**：开场镜给大景，让人看清场地与两人的相对距离和出口位置
2. **家具与高度差 = 攻击路线与逃生限制**：爬上、躲到台面下、滑过桌面、被墙逼到角落
3. **狭窄空间迫使正面冲突，开阔空间允许追逐与坠落**——空间形态本身就决定打斗形态
4. **利用纵深**：由远及近推进，是"透视"观感最扎实的实现方式

**写进提示词**：
> ✅ 开场镜："大全景，两人相距约五米，左侧是门，右侧是长桌"
> ✅ 空间约束镜："他退到墙边，背抵住墙，左右都是死角"

## 四、节奏：「暂停—爆发—暂停」

研究香港电影的波德维尔把动作链的普遍结构概括为 **「暂停—爆发—暂停」**：短暂的停顿通常出现在一连串进攻被格挡的瞬间，既标出动作流的阶段，也制造了节奏。这个结构源自戏曲的"亮相"——动作段落被拆成一个个单元，**急攻与骤停相互交替**。

### 落地成三个东西

**1. 镜内的终结与停顿**

每个「冲击」拍不要从头打到尾，而要写一个**终结动作 + 短停顿**：
> ✅ "拳击中对方脸颊，对方头部偏向一侧，**两人同时静止半秒**，只有衣角还在动"

**2. 整场的"呼吸点"**

打斗不能一直高能，中途必须让双方**停下来**。停顿不是浪费，它让下一次爆发更响。
- 对峙、喘气、对视、擦嘴角、捡起掉落的武器
- **呼吸点要单独成镜**，不要在同一个镜里塞"打 + 停"

**写进提示词（呼吸点镜）**：
> ✅ "两人分开站定，相距三米，胸口剧烈起伏，互相对视，没有攻击动作"

**3. 外部变量介入（高级手法，院线级打斗几乎都有）**

袁和平在张晋与杨紫琼的打斗中，让朋友**抛过来一根铁棍**——武器状态一变，攻防节奏与打法全变，同时镜头切两个特写眼神，**既完成了呼吸，又预告了下一轮**。

**写进提示词**：
> ✅ "一根铁棍从画面右侧抛入，他单手接住，握棍的手腕转半圈，棍身横在身前"

> 这一手同时解决三件事：节奏有个断点、攻防关系重置、观众的注意力被重新抓住。

## 五、力量的视觉证据（"实在感"从哪来）

袁和平说得很准：**"功夫可以不写实，但拍出来不能没有实在感。"**

力量不能靠"很重""很猛"表达，只能靠**证据**。按"可信度 × AI 友好度"排序：

| 证据 | 写法 | AI 友好度 |
|---|---|---|
| **承受者的形变** | 身体弯折方向、头部后仰幅度、踉跄的步数 | ⭐⭐⭐ 高（单人，不涉及接触） |
| **环境破坏** | 墙面碎裂、桌面被踩裂、积水被掀起 | ⭐⭐⭐ 高（不需要多人接触） |
| **物体位移** | 桌椅被撞开、杯子震倒、尘埃扬起 | ⭐⭐⭐ 高 |
| **武器震颤** | 刀身余震、棍子被震得脱手 | ⭐⭐ 中 |
| **接触点形变** | 面部肌肉被挤压、肌肉凹陷 | ⭐ 低（AI 最弱） |

> **结论：把力量证据放在「承受者」和「环境」上，不要放在「接触点」上。**
> 这不是妥协——香港动作片本来就是这么做的（用**被击者的表情与身体疼痛的夸张**来渲染力量）。专业做法与 AI 可行性在这里刚好同向。

**进阶写法：不写"快"，写物理后果。** 高速是模型最难表现的属性，让**破坏的痕迹替速度发言**——每一项都是"某一帧上看得到"的速度证据：

> ✅ "被斩断的铜钟断面光滑如镜"（切得快 = 断面齐）
> ✅ "剑刃切开地面积水，拉出一道锋利的水刃，水面来不及合拢"（快 = 水被切开）
> ✅ "拳锋过处空气瞬间被排空，雨幕撕裂出一个大洞"（快 = 雨都被推开）

比"极快的一刀"有效得多——"快"是抽象属性，断面 / 水刃 / 真空带是可见证据。

> 打击的视觉反馈怎么分级、哪些特效进 prompt 哪些留剪辑台，见 `collision-fx.md` 的三级特效字典。

## 六、一攻一应：每一拍必须交代六件事

**这是全篇最重要的一条规则。** 打斗出现"双方各忙各的""像排练广播体操"，根因都是攻击没有对应的反应。

每一拍（一个镜头）必须写清六件事：

| # | 要素 | 例 |
|---|---|---|
| 1 | **谁发起** | 黑衣人（画面左） |
| 2 | **攻击哪个部位** | 右肋 |
| 3 | **接触还是落空** | 落空——对方侧身让开 |
| 4 | **对方如何回应** | 顺势用肘撞他的下颌 |
| 5 | **双方位置如何变化** | 两人互换，黑衣人退到画面右 |
| 6 | **给下一拍留什么接口** | 黑衣人右手已经扶住桌沿（下一拍要掀桌） |

第 6 条**最容易被忽略，但决定了剪起来是否连贯**。院线动作戏的每一拍都在为下一拍埋下一个动作的"起手式"——这样两颗镜头接起来时，观众感觉是一个连续动作被切开，而不是两段无关素材。

**写进提示词**：把 1–5 直接写成一句话，第 6 条写成句尾的一个"未完成的动作"。
> ✅ "他从画面左跨步上前，右拳打向对方右肋，对方侧身让开，顺势用左肘撞他下颌，两人互换位置；**他的右手同时扶住桌沿**"

> "攻击没有可见的反应 = 观众读成打空了。" 这条在院线拍摄与 AI 生成实测里都成立，是少数**两边完全一致**的原则。

## 七、力量的"组合拳公式"（一击的七要素）

一次重要打击，写全这七项，画面基本不会散：

```
预兆 → 加速 → 接触点 → 材质变化 → 受力方向 → 位移结果 → 余波
```

| 要素 | 写法 |
|---|---|
| 预兆 | 肩部先动、膝盖微屈、手腕内旋（"起手"） |
| 加速 | 手臂划过的路径（"自下而上"、"由外向内"） |
| 接触点 | 撞在**前臂**上 / 击中**下颌**（部位要具体） |
| 材质变化 | 衣料凹陷、金属火花、积水被砸开 |
| 受力方向 | 对方肩膀向**右后方**偏转（方向必须写） |
| 位移结果 | "鞋底擦过积水滑出半步"（给具体量） |
| 余波 | 尘埃落、衣角余颤、武器震颤 |

> 只写"重重一拳"是抽象的；写全七要素，画面就成立了。

## 八、先选"打斗感"，再设计（两套体系）

**"院线级打斗"不是一个东西，是两套对立体系。先让用户选，选完之后所有参数都不同。**

| | **港式（表演型）** | **好莱坞式（生存型）** |
|---|---|---|
| 参照 | 《醉拳2》《叶问》《精武英雄》 | 《谍影重重》《疾速追杀》 |
| 感受 | **惊叹**：技艺、美感、编排 | **紧张**：粗暴、效率、生存 |
| 镜头 | 稳定、广角、跟随演员 | 手持、晃动、快速摇推 |
| 成片镜长 | **长（5–10 秒），10+ 招不打断** | 短（1–2 秒），3 招拆成 5–6 镜 |
| 编排 | 节奏化、杂技化，攻防往返清晰 | 近距离、肘膝、随手武器 |
| 参考长片的下场 | 镜太长则 AI 一致性会崩 | 天然适合 AI（本来就要碎剪） |

### 对 AI 生成的现实建议 ⭐

**用港式的美学标准（清晰的攻防 + 完整的动作路径 + 停顿节奏）+ 好莱坞式的镜头长度（1–2 秒）来生成。**

也就是「**用碎镜讲连贯的招式**」——这是当前模型能稳定产出的最优解：既保住了港式的"看得懂"，又避开长镜的动作精度与一致性问题。

## 九、生成时长 ≠ 成片镜长（一个必须讲清的换算）

这里有一个容易混淆、也容易烧钱的地方：

| 概念 | 典型值 | 由什么决定 |
|---|---|---|
| **生成单元**（一条 prompt 产出的片段长度） | 4–10 秒 | 引擎档位与成本 |
| **成片镜长**（剪辑后每个镜头的长度） | 动作戏 1–2 秒 | 节奏 |

**生成单元刻意长于成片镜长，是给剪辑留余量，不是浪费。** 做法：

- 一拍生成一个 5 秒的动作单元
- 成片里把它**分段使用**：取 0–1s 作 A 的攻击镜，中间插入 B 的反应镜，再取 3–4s 作 A 的后续动作
- 这就是"交替单人镜头"——**A 攻击 → B 反应 → A 继续**，既避免了同框精确交互（AI 最弱），又靠剪辑接出连贯感

> 所以：动作戏不要指望"一镜到底拍完整场"（长镜对 AI 极难），也不要担心"生成 5 秒只用 1.5 秒"（余量是给剪辑的）。

## 十、清晰度优先（快切不乱的秘密）

《疯狂的麦克斯：愤怒道》的做法叫**十字景框**：把重要视觉元素**放在画面中心**，即使加快切速也不会乱。

三条可执行规则：

1. **主体居中**：快节奏镜的主体放在画面中心区，不要压边
2. **朝向明确**：每个镜都写清"面朝画面右 / 背对镜头偏左"
3. **一次只交代一件事**：一镜里不要同时有"两人缠斗 + 武器飞舞 + 环境破坏"

**自检法（清晰度测试）**：随意暂停任意一帧，**角色的身体朝向是否清晰**？看不清就是设计失败。

> 这一条比"快剪"更本质：快剪之所以常被批评"看不清"，不是因为快，是因为**主体没居中、朝向没交代**。

## 十一、动作戏的输出顺序（设计 → 分镜 → 提示词）

```
① 四问（为什么打/谁强谁弱/什么武器/打多久）
      ↓
② 选体系（港式表演型 / 好莱坞生存型）
      ↓
③ 定空间（场地、道具、出口、高度差）
      ↓
④ 划节奏弧线（哪几处呼吸点？有没有外部变量介入？）
      ↓
⑤ 写「一攻一应」表（每拍六要素，含"给下一拍留接口"）
      ↓
⑥ 四拍拆解 → 分镜表（方位列 + 转场列）
      ↓
⑦ 逐镜 prompt（主体动作 → 景别角度 → 单个运镜 → 光线 → 色彩 → 画幅时长 → 声音）
```

**第 ⑤ 步产出的表，就是主模板输出契约里的「打斗设计表」。** 它必须出现在四拍拆解表之前——先想清楚打什么，再决定怎么拍。

## 十二、打斗的边界：怎么开场、怎么收场

打斗戏的成败，有相当比例落在**第一个镜头和最后一个镜头**。中间打得再对，头尾塌了照样废。

### 开场：三件事必须在前 3 秒完成

| # | 事 | 做法 |
|---|---|---|
| 1 | **教会地理** | 大景交代场地、两人的相对距离、出口与高度差（见第三节） |
| 2 | **交代力量对比** | 让观众一眼看出谁占优、谁危险——体型差、武器、站位、人数（多人戏见 `multi-opponent-design.md` 第一节） |
| 3 | **给出"为什么现在打"** | 一个触发动作：放下茶杯、拔刀出鞘半寸、抬头。没有诱因的开场 = 两人突然开始打 |

> ❌ 开场两人站桩对视两秒（观众不知道看什么）
> ✅ "大全景，两人相距五米，左侧是门右侧是长桌；他放下茶杯站起身，对方同时握紧了刀柄"

### 收场：三件事

| # | 事 | 做法 |
|---|---|---|
| 1 | **静止的狼藉** | 环境的"账单"（见 `environment-atmosphere.md` 恶化曲线），一切停止 |
| 2 | **代价可见** | 胜者也要付出点什么：跪地、喘息、血、脱手的武器。**没有代价的胜利不可信** |
| 3 | **关系被改变的姿态** | 最后一个镜头给一个"从此不同了"的姿态：搀扶、背对、收刀入鞘、转身离去 |

> **最后一帧不要是"打完就黑"。** 给一个静止的画面 2 秒，让情绪落地。

### 高级收场：延迟爆碎（杀伤结果后置一镜）

居合斩的经典收尾：**先收招，后爆发**。终结一击时双方错身穿透而过（画面上"什么都没发生"），下一镜收剑入鞘、剑格"咔哒"闭合的瞬间，延迟的剑芒才把背景撕裂。

三步写法：

1. **错身镜**："连人带剑从对方身侧错身穿透过，停在远处"——**不拍命中瞬间**。接触点形变本就是 AI 最弱项（见第五节），错身直接绕开
2. **残心镜**："背对对方缓缓推剑入鞘，电弧在鞘口跳跃；对方仍保持扑杀姿势一动不动"（对方静止 = 力量已经发生完毕，只是还没显示）
3. **延迟镜**："剑格闭合轻响的瞬间，一道剑芒从画面左下至右上把身后的建筑斜切两半，被斩断的铜钟断面光滑如镜"

为什么有效：观众在"入鞘的静"与"爆发的烈"之间自己完成一次脑补，张力远大于直接拍命中。它同时是收场三件事的变体——**静止的狼藉（撕裂的废墟）+ 代价可见（倒下的对手）+ 关系被改变的姿态（入鞘）**。

### 一个常见错误：把打斗当独立段落

打斗的前后要有**钩子**——前一镜留一个未解决的问题（他要找的人不在），后一镜接上后果（他找到了，但付出了代价）。脱离上下文的打斗再精彩也是素材，不是戏。
