# 动作 / 战斗内容合规红线

> 动作戏天然涉及暴力，平台审核严格。发布前务必过一遍平台后台的尺度检测。以下为 2026-10 时点的主要规则，过时以平台最新规范为准。

## 1. 血腥与伤情尺度

- 允许：打击感（碎屑、扬尘、武器震颤、受力位移）、瘀伤、汗血混合的写实质感。
- 受限/禁止：喷血特写、断肢、内脏、过度血肉模糊的慢放。多数平台对"明显血腥"限流或下架。
- 建议：用"暖色光点/尘屑"替代真实喷血；伤口以暗红小块+快速切走处理。

## 2. 武器 depiction

- 冷兵器（刀剑棍棒）在影视化打斗中通常可通过，但避免**教学式**展示杀伤细节。
- 枪械：多数短视频平台对实景枪械极度敏感，易触发审核；用"光束/能量武器/剪影"替代更稳妥。
- 异能/奇幻武器（光刃、法术）安全度高，首选。

## 3. 暴力美化边界

- 禁止把暴力呈现为**无后果的爽感酷刑**或针对特定群体的攻击。
- 允许：正邪分明的动作戏、竞技格斗、自卫反击，且有明确因果。
- 避免：随机施暴、虐杀快感、现实仇杀映射。

## 4. 未成年人与真人

- 不生成未成年人参与暴力打斗的画面。
- 写实真人打斗注意肖像权与"疑似真实事件"的误导风险；用明显风格化/奇幻设定降低歧义。

## 5. 平台特殊规则（抖音 / 视频号 / 小红书）

- 前 3 秒避免直接血腥冲击（易被首屏审核卡）。
- 标题与封面不堆"血""杀""死"等刺激词。
- 战斗结果建议落在"制伏/脱险/成长"而非"致死"。

## 自检（发布前）

- [ ] 无喷血/断肢/内脏特写
- [ ] 武器为风格化或冷兵器，非实景枪械教学
- [ ] 暴力有因果、正邪分明，无美化虐杀
- [ ] 无未成年人参与暴力
- [ ] 标题封面无过度刺激词
- [ ] 已过平台后台尺度/违禁词检测

---

## 6. 超现实 / 奇幻内容的额外规则

奇幻、修仙、超能力题材在审核上**有优势也有新坑**：风格化设定天然降低"真实暴力"的认定风险，但能量伤害、光效轰炸、伤害表现方式会触发另一类判定。

### 6.1 风格化是优势，要主动用

- 奇幻设定（光刃、法术、能量武器）**安全度显著高于实景兵器与写实血腥**——平台更容易把它认定为"虚构特效"而非"真实暴力"。
- 伤情优先用**非血肉方式**呈现：能量消散、光点溃散、衣袍破损、跪地力竭。这既是合规选择，也是 AI 更擅长生成的（写实血肉是模型弱项，又是审核雷区）。

### 6.2 能量伤害不要拍成"肢解"

- ❌ 光束穿透身体、肢体被能量撕裂、身体碎裂成块——即使风格化，也容易被判为"血腥/暴力展示"。
- ✅ 被击中后**失去战斗力**：跪地、武器脱手、气旋溃散、单膝触地口角溢血（少量）。

### 6.3 满屏光效的审核风险

- 长时间高频闪光、全屏爆闪、密集光污染，可能触发**光敏性癫痫**相关提示与限流。
- 抖音/视频号对前 3 秒的爆闪尤其敏感。**大招光效控制在 1–2 秒内，且之前给一个"静"的铺垫**（这正好和 `supernatural-fight.md` 的"特效只出现在起手与命中两端"同向）。

### 6.4 结果必须落在"制伏 / 脱险 / 成长"

- 战斗结果建议是制伏、脱险、守护、顿悟，**不要是致死**。
- 这不是妥协——"剑停在咽喉前一寸"比"一剑穿喉"更有张力，且同时满足合规与"停点"技巧（见 `concept-translation.md` 第六节）。

### 6.5 借梗风险

- 明显影射真实宗教符号、现实暴力事件、特定政治意象的法术与造型，一律避开。
- 自创的符文、结印、招式名最安全。

### 6.6 超现实自检（追加）

- [ ] 伤情以能量消散 / 力竭 / 跪地呈现，无光束穿体、无肢体碎裂
- [ ] 大招光效 ≤2 秒，前有静默铺垫，无长时间高频爆闪
- [ ] 战斗结果落在制伏/脱险/成长，非致死
- [ ] 无法术符号借梗真实宗教或现实事件
- [ ] 标题封面无过度刺激词（"血""杀""死"不堆）
