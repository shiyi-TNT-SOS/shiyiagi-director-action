# 动作镜头语法速查（七维 + 清晰度 + 体系）

> 动作戏专用的镜头语法。七维：景别 / 角度 / 运镜 / 光学 / 光影 / 色彩 / 表演调度。
> 每维给「动作常用值 + 作用 + 反例」。普通导演四层结构见 `shiyiagi-director-ad-tvc` 的 lens-grammar，本文件只讲动作差异点。

## 1. 景别（决定信息量与压迫感）

| 景别 | 动作用途 | 注意 |
|------|----------|------|
| 特写 CU | 拳头/刀锋/正脸表情/伤口细节 | 给正脸或手部，不给复杂多人同框 |
| 近景 MCU | 上半身发力、武器挥动 | 力度戏主力景别 |
| 中景 MS | 完整动作轨迹、位移 | 冲击拍常用 |
| 全景 WS | 反应拍、环境交代、走位 | 反应拍收尾常用 |
| 大全景 EWS | 规模感、地形 | 透视/满屏观感时配合广角 |

## 2. 角度（决定权力关系与英雄感）

- **低角度 15–25° 仰拍**：英雄镜，主体压迫感、帅气感的主来源。
- **平视**：写实、对等交手。
- **高角度俯拍**：弱势、被压制、悲壮。
- 打斗中多用低角+偶尔俯拍形成权力反转。

## 3. 运镜（动作戏的灵魂，逐帧设计）

| 运镜 | 用于哪拍 | 作用 |
|------|----------|------|
| 微推 / 静止 | 预备 | 蓄力张力，镜头像屏住呼吸 |
| 甩镜 whip pan | 冲击 | 瞬间加速、空间跳切、力量爆发 |
| 跟拍 / 移动 | 长镜头 | 维持连贯，不切机位 |
| 定格 hit-stop 1–2帧 | 结果 | 打击感峰值，强化冲击 |
| 拖影 / 慢动作 | 反应 | 余势、悲壮、时间拉长 |
| 径向模糊 | 炸裂/冲击帧 | 从中心向外炸开的视觉 |

> 单镜只放一拍的运镜，不要一镜里又是甩又是慢又是跟——模型会糊。
>
> ⚠️ **别混淆两个"单镜时间"**：**生成单元**（一条 prompt 产出的片段，通常 4–10 秒）≠ **成片镜长**（剪辑后，动作戏 1–2 秒）。生成刻意留长是**给剪辑留余量**——一拍生成 5 秒，成片里分段取用，中间插入对方的反应镜（A 攻击 → B 反应 → A 继续）。详见 `fight-design.md` 第九节。

## 4. 光学（焦段与虚化）

- **广角 ≈24mm 等效**：透视畸变、引导线、前景虚化、纵深调度（"透视"观感的核心）。
- **中长焦 85mm+**：压缩背景、突出主体、电影感（但宽画幅下主体要够大）。
- 前景虚化 + 主体清晰 = 层次与速度感。

## 5. 光影（硬光出打击，软光出情绪）

- **硬光侧逆光勾边**：动作戏主力，把人物从背景"刻"出来，帅气感来源。
- **顶光**：审讯、压迫、孤独。
- **冷暖对撞**：冷调环境 + 暖色血/火/光，炸裂与悲壮的标配。
- 避免平光大白——动作戏平光=没有体积感=塑料感。

## 6. 色彩（用色讲力度，不用词讲）

- 冷调青灰底 + 暖血色/火光点缀 = 写实狠辣。
- 高饱和暖调 = 凌厉热血。
- 去饱和灰调 = 悲壮克制。
- 不要全片一个色——力度靠冷暖对比，不靠"加滤镜"形容词。

## 7. 表演调度（力度长在动作上）

- 写出**重心转移、关节角度、发力方向位移量**，比写"猛"有用十倍。
- 多人接触：一拳到肉即切，不拍连续缠斗；复杂缠斗移出画面或只拍单人反应。
- 面部微表情交给肢体与调度；特写给正脸，不给侧脸乱抿嘴（AI 嘴部最弱）。

## 8. 清晰度优先（快切不乱的秘密）

快剪之所以常被批评"看不清"，**根源不是快，是主体没居中、朝向没交代**。《疯狂的麦克斯：愤怒道》的做法叫**十字景框**——把重要视觉元素放在画面中心，即使加快切速也不会乱。

三条可执行规则：

1. **主体居中**：快节奏镜的主体放在画面中心区，不要压边
2. **朝向明确**：每镜都写清"面朝画面右 / 背对镜头偏左 / 视线朝画面左下"
3. **一次只交代一件事**：一镜里不要同时有"两人缠斗 + 武器飞舞 + 环境破坏"

**清晰度自检**：随意暂停任意一帧，**角色的身体朝向是否清晰**？看不清就是设计失败。

> 朝向词还有一个隐藏收益：它同时起到锁定视角的作用，能抑制"同一镜内角度乱变"（详见 `concept-translation.md` 第七节的顺序分歧）。

## 9. 两套体系的镜头差异（先选体系再定镜头）

| | 港式（表演型） | 好莱坞式（生存型） |
|---|---|---|
| 镜头 | 稳定、广角、跟随演员 | 手持、晃动、快速摇推 |
| 成片镜长 | 长（5–10 秒），动作完整不打断 | 短（1–2 秒），碎剪 |
| 景别 | 偏向中景/全景，看得见完整身体与走位 | 偏向近景/特写，压迫感 |
| 感受 | 惊叹：技艺、美感 | 紧张：粗暴、生存 |
| 对 AI 的友好度 | 长镜一致性会崩 | 天然友好 |

**对 AI 的现实建议**：**用港式的美学（清晰的攻防 + 完整的动作路径 + 停顿节奏）+ 好莱坞式的镜长（1–2 秒）**，即「**用碎镜讲连贯的招式**」。这是当前模型能稳定产出的最优解。详见 `fight-design.md` 第八节。

---

## 一句话铁律

**力度不靠形容词，靠重心位移 + 形变 + 碎屑 + 定格。** 镜头语法只是把这条落到画面上。
