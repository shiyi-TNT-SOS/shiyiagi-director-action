# 碰撞特效分级与防崩护栏（三级字典）

> 本文件回答两个问题：**碰撞特效怎么分级才跨镜一致？哪些特效引擎能执行、哪些必须留剪辑台？**
> 与 `concept-translation.md` 的关系：那里是"观感词→元件"的通用转译表；这里是打斗专用的**碰撞特效分级字典**——把"冲击帧/打击感"按碰撞强度做成固定配方，全场复用。

## 一、为什么碰撞特效要"分级固定"

打斗特效最大的翻车不是"没有特效"，是**每镜特效随手写、强度对不上、跨镜不一致**——轻碰炸出蘑菇云、重击只有一圈涟漪，观众对力量的感知立刻崩掉。

解法是**开打前定一张三级特效字典，全场复用**：碰撞强度 → 固定视觉配方。好处三个：

1. **力量可视化**：观众靠特效强度差读出招式轻重
2. **跨镜一致**：同一个"重碰撞"在任何镜里长得一样，剪起来像同一部戏
3. **提示词省预算**：字典定一次，逐镜 prompt 只写"轻碰撞触发"，不重复整段配方

## 二、三级特效字典（模板）

开打前按下表定好全场配方（示例值可换，**三级结构不能省**）。关键设计：**每级特效拆成两列——进 prompt 的（引擎可执行）与留剪辑台的（后期实现）**：

| 级别 | 触发时机 | 进 prompt（引擎可执行） | 留剪辑台（后期实现） |
|---|---|---|---|
| **轻碰撞** | 格挡 / 擦碰 / 点刺 | 冲击帧定格 1–2 帧（hit-stop）、火星拉丝、细小碎屑、镜头轴向微震 | 抽帧节奏、局部闪白、轻微 shake 微调 |
| **重碰撞** | 实招命中 / 兵刃对撞 | 放射状冲击帧、受力方猛沉后回弹、三层流体爆开（水花/雾气/碎屑）、环境破坏（墙裂 / 地陷 / 积水掀翻） | 中心负片、径向 shake、低频音效铺底 |
| **大招爆发** | 全场仅 1 次（见 `supernatural-fight-design.md` 大招经济学） | 全屏冲击帧定格 0.15–0.3s、强光泛光、环形气浪推飞雨雾尘土、受击方位移夸张 | 全屏负片闪白、鱼眼畸变、变速曲线（time ramp） |

**写进 prompt 的格式**——碰撞段紧跟主体动作（碰撞是动作的物理结果），特效"锚定"在具体动作与载体上：

> ✅ "双剑相撞，冲击帧定格一瞬，火星拉丝四溅，两人各退半步，脚下青石板裂开蛛网纹"
> ❌ "重碰撞触发！0.1s 抽帧 + 中心负片 + 径向震荡"（抽帧 / 负片 / 径向震荡是剪辑台词汇，模型不执行）

> **分流判据（与 `concept-translation.md` 同源）**：画面**某一帧上看得到** → 进 prompt；只能在**播放或剪辑时存在**（抽帧节奏、负片、鱼眼、径向震动、速度曲线）→ 进剪辑台。
> 例外提示：冲击帧 / 定格 / 升格这类源自动漫语汇的效果，部分引擎能响应，可低成本试一次；负片 / 鱼眼 / 精确到 0.05s 的抽帧不要试。

## 三、特效贴附：特效要"长在"载体上，不许飘

AI 特效最大乱象是**飘散**：水流火焰不贴武器和身体，满屏乱舞变光污染。两条写法：

1. **贴附词**：写"死死贴附在衣甲与剑刃上""缠绕在剑身不散"，不写"周身环绕着火焰"（"周身" = 无边界 = 满屏糊）
2. **恒定伴随**：角色的标志性特效写成固定一句——"身后始终附带一道贴地流动的蓝黑水流残影"——**每镜逐字复用**，特效就成了角色的"固定描述串"（与武器描述串同一逻辑，跨镜一致）

> ✅ "剑身缠绕蓝黑水流，水流死死贴附剑刃，挥剑时拖出浓重水流残影"
> ❌ "周围充满蓝色能量"（无载体、无边界，必然糊成一团）

## 四、特效标绝对时长（可执行度换挡）

"瞬间 / 快速 / 一下"是废词。特效时段写**绝对时长**，可控度立刻上一个档：

| 写法 | 例 |
|---|---|
| 定格 | "冲击帧定格 0.2 秒" |
| 升格 | "升格慢放 0.3 秒，只见雨珠悬停"（**升格段独立成镜**，见 `supernatural-fight.md` 第五节硬约束） |
| 维持 | "环形气浪持续 1 秒后消散" |

> ⚠️ 边界：prompt 里的绝对时长只用于**画面内可见的持续状态**（定格 / 维持 / 升格段），不用于剪辑节奏——0.05s 级的抽帧、快慢交替（time ramp）是剪辑台的活，模型做不了，写了等于给画面加噪音。

## 五、防崩护栏三连（打斗高频崩点）

| 崩点 | 护栏写法 | 原理 |
|---|---|---|
| **转体失控**（旋转过头 / 肢体乱甩） | "所有翻转旋转不得超过 360 度" | 模型对多圈旋转必崩；一圈封顶，连续感靠快切补 |
| **滑步**（下盘像溜冰） | "全程跑动，无需滑步""步点扎实踩进地里" | AI 打斗默认整体漂移，必须明写脚与地面的接触 |
| **站桩输出**（上半身打、下盘不动） | "绝对零站桩，每一击都在移动中完成" | 每击带重心位移；与姿态链（3–5 关键姿态）同用 |

## 六、组装顺序与一镜自检

特效内容嵌进七段框架（`ai-video-prompt.md`），不破坏"主体动作在最前"：

```
[主体动作：招式+路径] → [碰撞段：级别+载体+配方（字典取用）] → [景别角度] → [单运镜] → [光线] → [色彩] → [画幅+时长] → [声音]
```

一镜自检四问：**这一镜碰撞是几级？配方是不是从字典取的？特效贴附在什么载体上？有没有后期词混进 prompt？**
