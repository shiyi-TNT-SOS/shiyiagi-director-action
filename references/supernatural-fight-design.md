# 超现实打斗设计层：一场"违反物理"的打戏怎么设计

> **对应关系**：写实打斗（拳脚 / 兵器 / 追车）的设计层见 `fight-design.md`，本文件处理奇幻武侠 / 超能力 / 修仙 / 赛博格斗。
> 分工：`supernatural-fight.md` 解决「单镜怎么写」，本文件解决**更前面的一步——这场打斗本身怎么设计**。

---

## 零、根子：超现实打斗崩在哪

实拍打斗崩，是**镜头糊**——看不清谁打谁。
超现实打斗崩，是**观众不知道谁为什么赢**。

原因很直白：瞬移、飞行、护体罡气把"体力"这个真实约束拿掉了。剩下的就是两个神明互相发光、互相弹开、然后一方突然倒下。

**解法不是加更多特效，是把"能力"变成可理解的规则。**

---

## 一、先签「能力契约」（地基，不能跳）

| # | 要素 | 必须写清 |
|---|---|---|
| 1 | **能力清单** | 双方各会什么。**每个能力都必须能翻译成一个可见效果**（光尘 / 气浪 / 光带），不能只会"很强" |
| 2 | **代价与盲区** | 瞬移的盲区、大招的蓄力、超高速的身体负担、能力的使用次数 |
| 3 | **胜负条件** | 这场怎么算赢（击倒 / 破防 / 拖到对方力竭 / 抢到某物） |
| 4 | **情报差** | 谁不知道对方有什么能力——这是悬念的来源 |

> **核心认知：实拍打斗的张力来自体力与技术的交换；超现实打斗的张力来自"能力情报"的交换。**
> 不写能力契约 → 两个神明互相发光 → 观众不知道谁为什么赢。

---

## 二、力量对比换成「克制关系」

写实看体型、力量、速度；超现实必须看**克制链**。

| 关系 | 设计要点 |
|---|---|
| **被克制者胜**（最有戏） | 强者的杀招有代价或盲区，弱者靠找到它翻盘 |
| **克制者胜** | 但过程必须付出代价（受伤 / 力竭 / 失去某物），不能轻松碾压 |
| **相生相杀** | 来回反制，适合势均力敌 |

三条纪律：

1. **境界差不能做成纯数值**——"他修为高所以随便赢"是最差的写法
2. **每个大招必须存在"被反制的可能"**
3. **反制的线索要提前埋**（前面给过一个特写：对方的盲区在地上 / 背后 / 灵力流向异常）

---

## 三、空间：距离失效了，限制必须换

`fight-design.md` 说"空间是打斗的一半"——但那靠的是出口、桌台、高度差。**瞬移和飞行让"距离"失效，所以约束必须换轴**：

| 写实打斗的约束 | 超现实的替代 |
|---|---|
| 距离 / 出口 | **感知范围**——瞬移必须知道要去哪，超出感知就不能瞬移 |
| 高度差 | **领域 / 结界 / 法阵的覆盖范围** |
| 遮挡 / 死角 | **遮蔽感知**——障碍物能挡住瞬移的锁定 |
| 场地物件 | **可被能力波及或利用的环境**（水导电、火借风势、竹林可藏） |

> **超现实打斗的"地理"不是地形，是能力的作用范围与盲区。**
> 设计空间时该问的不是"这里有什么家具"，而是"**这里哪些位置对双方是不安全的 / 到不了的**"。

---

## 四、阶段结构：情报战四段式（超现实独有）

```
① 试探 ──→ ② 暴露 ──→ ③ 反制 ──→ ④ 终结
 互扔小招      被迫亮出      找到盲区      决定性一击
 摸清能力范围   底牌          与代价        + 支付代价
```

| 段 | 内容 | 常见错误 |
|---|---|---|
| **试探** | 双方用次级招式互探，摸清能力范围与反应速度 | 一上来就放大招 |
| **暴露** | 一方被迫亮出底牌（被逼入绝境 / 被打怒） | 没有"被迫"，大招随便放 |
| **反制** | 另一方找到盲区或代价，**针对性反制** | **直接省略 → 变成数值对轰** |
| **终结** | 决定性一击 + 代价支付（吐血 / 力竭 / 失去武器） | 大招放完对方就倒了，没有代价 |

**③ 是整场戏的命门。** 没有反制，前两段再炫也只是互相扔特效。

四段各占一到两拍，共 4–8 镜；每段内部仍按四拍拆解。

---

## 五、一攻一应的超现实版（六要素升级）

把 `fight-design.md` 的六要素换成能力的语言：

| # | 写实版 | 超现实版 |
|---|---|---|
| 1 | 谁发起 | 谁发起，**用哪个能力** |
| 2 | 打哪个部位 | 能力的**作用目标**（锁定的对象） |
| 3 | 接触还是落空 | **命中 / 闪避 / 格挡 / 免疫 / 反噬** |
| 4 | 对方如何回应 | 对方**用什么能力反制**（超现实独有） |
| 5 | 位置如何变化 | **空间如何被能力折叠**（瞬移 / 升空 / 被击飞撞穿墙） |
| 6 | 给下一拍留的接口 | **代价或盲区被暴露** |

> 例：他从画面左瞬移到对方背后，右拳砸向对方后心；对方背后浮起一道环形护盾，拳锋撞在盾上被弹开，他整个人被反震退三步，**落地时单膝跪地、左手撑地**（下一拍要支付的代价）

---

## 六、大招经济学：节奏靠「省着用」

- **一场打戏只安排 1 个决定性大招**，1–2 个次级招式，其余用基础技填充
- 大招必须有**蓄力 / 前置**——这是天然的"预备拍"素材
- 大招之后必须有**真空期**（代价期）——这是天然的"反应拍"素材
- **观众以为的大招，最好不是真正的杀招**（先放一个大的，被反制，再放真正的）

> 实拍动作戏靠体力限制节奏；超现实靠**能力代价**限制节奏。**代价就是超现实世界的"体力条"。**

---

## 七、最大的视觉陷阱：特效盖住动作

**光效越大，动作越看不清。** 满屏特效的打斗在实拍里是浪费，在 AI 里是灾难——模型的肢体精度本来就不高，再被光效一盖，人变成一团发光的水母。

四条纪律：

1. **特效只出现在起手与命中两端**，中间路径留干净
2. **人必须始终可辨**——光效是"边"，不是"体"；主体轮廓不能被特效吃掉
3. **大招时反而要给特写**——看的是表情、姿态、衣袍被气劲掀起，不是看光
4. **能力形态要小而准**：一道定向光带 > 一团弥散光雾

## 八、三条路子（先选，再设计）

| 路子 | 张力来源 | 节奏 | 参照 |
|---|---|---|---|
| **中式仙侠 / 武侠** | 意境、境界、一瞬定胜负 | 慢—快—停，姿态优美 | 《将夜》《诛仙》 |
| **日式异能 / 战斗** | 规则、情报、代价、连环反制 | 快节奏智斗，规则解释 | 《火影》《咒术回战》 |
| **赛博 / 科幻** | 装备、能量、技术限制 | 装备切换、能量管理 | 《阿基拉》《赛博朋克》 |

**共同点是都要有"能力规则"。** 区别只在于规则讲得诗意一点，还是精确一点。

---

## 九、输出顺序

```
① 能力契约（双方能力 + 代价盲区 + 情报差）
      ↓
② 克制关系（谁克谁、谁靠盲区反制、反制线索埋在哪）
      ↓
③ 重定义空间（感知范围 / 领域覆盖 / 遮蔽感知 / 可利用环境）
      ↓
④ 阶段结构（试探 → 暴露 → 反制 → 终结）
      ↓
⑤ 大招排布（几个大招、蓄力多长、真空期多久）
      ↓
⑥ 一攻一应表（超现实版六要素）
      ↓
⑦ 四拍拆解 → 分镜表（方位列 + 能力状态列）
      ↓
⑧ 逐镜 prompt（过渡态必须可见，见 supernatural-fight.md）
```

**④ 和 ⑥ 就是主模板输出契约里的「打斗设计表」，必须出现在四拍拆解表之前。**

## 十、自检清单（超现实打斗设计）

- [ ] 双方能力清单已写，**每个能力都有可见形态**（没有"很强"这种能力）
- [ ] 每个大招都有**代价或盲区**，且观众能看懂
- [ ] 存在**克制关系**，不是纯数值高下
- [ ] 空间约束已换成**感知范围 / 领域覆盖 / 遮蔽感知**，没有停留在"距离和出口"
- [ ] 阶段结构四段齐全，**③ 反制没有省略**
- [ ] 反制的线索在前面**已埋过**（不是天降解法）
- [ ] 全场只排 1 个决定性大招，前后有蓄力与真空期
- [ ] 一攻一应表用超现实版六要素（第 6 列是"代价或盲区被暴露"）
- [ ] 特效只出现在起手与命中两端，**主体轮廓始终可辨**
- [ ] 大招镜头给了人的特写，不是只给光
